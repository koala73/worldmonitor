WorldMonitor exposes its hosted MCP server at `https://worldmonitor.app/mcp` over Streamable HTTP, with OAuth 2.1 sign-in (PKCE, Dynamic Client Registration and Client ID Metadata Documents). Antigravity uses the same server, tools and entitlements as other supported clients. Gemini listing preparation is described below; its custom-app OAuth callbacks are not currently supported. Pro-only tools stay Pro-only. See the [MCP Server overview](/mcp-overview) for auth, quotas and the tool list.

## Google Antigravity

### Install the plugin

The repository ships an Antigravity plugin manifest at `.antigravity-plugin/plugin.json`. It bundles the two MCP servers in `mcp_config.json` and the agent skills in `skills/`.

```bash
git clone https://github.com/koala73/worldmonitor
agy plugin validate --strict ./worldmonitor
agy plugin install ./worldmonitor
agy plugin list
```

When the Marketplace listing is live, install it with `agy plugin install worldmonitor@antigravity-plugins-official`.

### Add the server manually

In the Antigravity IDE, open **... > MCP Servers** in the agent side panel and edit `mcp_config.json`. In the CLI, use `~/.gemini/config/mcp_config.json` (global) or `.agents/mcp_config.json` (workspace):

```json
{
  "mcpServers": {
    "worldmonitor": { "url": "https://worldmonitor.app/mcp" }
  }
}
```

Antigravity's OAuth callback, `https://antigravity.google/oauth-callback`, is already on the [redirect URI allowlist](/mcp-overview#redirect-uri-allowlist).

## Gemini

### Developer Mode (custom app)

Gemini custom-app OAuth callbacks are not currently supported by WorldMonitor's [redirect URI allowlist](/mcp-overview#redirect-uri-allowlist), so authenticated tool calls are not ready to use through this flow. Public tool discovery alone does not verify sign-in or paid access.

Once callback support has been implemented and verified, follow Google's [Developer Mode guide](https://developers.google.com/connected-apps/mcp/dev-mode/usage): choose **+ Create new**, enter `https://worldmonitor.app/mcp` as the MCP Server URL, accept the security notice and connect.

### Connected App listing metadata

These values are used when registering WorldMonitor in the [Google Connected Console](https://connected.google.com/console).

Before submitting, complete console-issued domain verification, confirm that Google's app-specific OAuth redirect URIs are accepted, and test end to end with a Pro account.

| Field | Value |
|---|---|
| Connected app name | WorldMonitor |
| Description (under 30 words) | Track world news, country risk, conflicts, markets, energy and shipping chokepoints with source-attributed live data. |
| Icon (512 x 512 PNG) | `https://www.worldmonitor.app/favico/android-chrome-512x512.png` |
| MCP endpoint | `https://worldmonitor.app/mcp` |
| Auth | User-delegated OAuth (Authorization Code), dynamic registration (CIMD or DCR) |
| Terms of Service URL | `https://www.worldmonitor.app/docs/terms` |
| Privacy Policy URL | `https://www.worldmonitor.app/docs/privacy` |
| Website URL | `https://www.worldmonitor.app` |

Capabilities:

- Browse source-attributed world headlines
- Read country risk and intelligence briefs
- Check maritime chokepoint and energy disruption status
- Compare macro and market histories

Example prompts:

- @WorldMonitor what are today's top world headlines?
- @WorldMonitor summarize the current risk picture for Taiwan
- Check which shipping chokepoints are disrupted on WorldMonitor
