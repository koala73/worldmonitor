World Monitor plugs into your AI assistant as a connector. You paste one address, sign in with your World Monitor account, and the assistant can answer from live data covering {/* mcp-domains:start */}markets, commodities and macro; energy; conflicts, country risk, sanctions, cyber threats and chokepoints; maritime, aviation and supply chains; climate and natural disasters; health signals; displacement and humanitarian crises; AI briefs, forecasts and intel history; tariffs and trade policy{/* mcp-domains:end */}.

<Info>
**The address to paste:** `https://worldmonitor.app/mcp`

There is no API key to copy and nothing to install. You sign in with the same email you use on worldmonitor.app.
</Info>

## Claude

Works in the Claude desktop app, on claude.ai and in the mobile apps. You add the connector once and every Claude app on your account can use it.

<Steps>

  <Step title="Sign in with World Monitor">

On Claude Team and Enterprise, an owner first adds the connector under **Organization settings → Connectors**. Members then click **Connect** next to it in **Customize → Connectors**. Claude's Free plan allows one custom connector.
</Note>

## ChatGPT

<Steps>
  <Step title="Add the server">
    Open **Plugins**, click **+**, and choose **Add custom MCP server**. Name it `World Monitor`, paste `https://worldmonitor.app/mcp`, choose **OAuth** for authentication, and confirm.
  </Step>
  <Step title="Sign in and ask">
    Sign in with your World Monitor account in the window that opens, then pick World Monitor from the **+** menu in a chat.
  </Step>
</Steps>

ChatGPT moves this menu between releases and some plans or workspaces turn custom servers off. If you don't see it, follow [OpenAI's guide to custom MCP servers](https://help.openai.com/en/articles/12584461-developer-mode-and-mcp-apps-in-chatgpt).

## Codex

Run two commands. The second opens your browser to sign in.

```bash
codex mcp add worldmonitor --url https://worldmonitor.app/mcp
codex mcp login worldmonitor
```

The Codex app, the CLI and the IDE extension share this setup.

## Claude Code

```bash
claude mcp add --transport http worldmonitor https://worldmonitor.app/mcp
```

Then type `/mcp` in Claude Code, pick `worldmonitor`, and choose **Authenticate**.

## Cursor

[Add World Monitor to Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=worldmonitor&config=eyJ1cmwiOiJodHRwczovL3dvcmxkbW9uaXRvci5hcHAvbWNwIn0=) with one click, or put this in `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "worldmonitor": { "url": "https://worldmonitor.app/mcp" }
  }
}
```

Cursor shows **Needs login** next to the server under **Settings → MCP**. Click it to sign in.

## Other apps

Perplexity, Mistral Le Chat, Grok, Microsoft 365 Copilot, VS Code, Gemini CLI and most other assistants that support MCP take the same address as a custom connector or remote server. See [client setup](/mcp-overview#client-setup) for per-app notes.

## Questions to try

- _Draft a duty-of-care brief for our staff in Riyadh using today's World Monitor data._
- _Compare the US, UK and Australian travel advisories for the Gulf states. Which changed most recently?_
- _Is anything disrupting flights or shipping through the Strait of Hormuz right now?_
- _Give me a country brief on Venezuela with the main risks for the next two weeks._
- _How are oil, gold and the main equity indices moving today, and why?_

The assistant picks the right World Monitor tools on its own. Answers carry timestamps, so you can see how fresh the data is.

## What your plan includes

| Plan | What the assistant can use | Daily allowance |
| --- | --- | --- |
| Free account | Source listing and a small set of cached datasets | 5 calls |
| Pro | Every tool | 50 calls |
| Pro Business | Every tool | 250 calls |
| API Starter, API Business | Every tool, shared with your REST budget | 1,000 or 10,000 units (most calls cost 1–2) |
| Enterprise | Every tool | 25,000 calls |

A call is one request from the assistant to World Monitor. Allowances reset at 00:00 UTC. Upgrade at [worldmonitor.app/pro](https://www.worldmonitor.app/pro). Full limits are in [plans and limits](/mcp-overview#plans-&-limits).

## If something goes wrong

- **The sign-in window never opened.** Remove the connector and add it again, then click **Connect**. Pop-up blockers can stop the window.
- **Claude says "Connection has expired".** The sign-in lapses after about a week without use. Open **Customize → Connectors → World Monitor** and click **Reconnect**.
- **The World Monitor window keeps loading after a passkey prompt.** The passkey step was cancelled or timed out. Reload the window and sign in again, or use the email code.
- **The code email didn't arrive.** Check spam or quarantine. Corporate filters sometimes hold it.
- **The assistant says it needs a subscription.** Your account is on the free plan. Upgrade, then ask again; there's no need to reconnect. The new plan usually applies within a minute, and at most 15 minutes later.
- **The assistant doesn't use World Monitor.** Make sure the connector is switched on for that chat, and mention World Monitor in your question.

## For developers: scripts and API keys

Scripts and servers can call the same endpoint with a `wm_…` key from an API Starter or higher plan. Create one in the [dashboard](https://www.worldmonitor.app/dashboard) under **Settings → API Keys**.

```bash
export WM_KEY="wm_0123456789abcdef0123456789abcdef01234567"  # Replace with your API key

curl -s https://worldmonitor.app/mcp \
  -H "X-WorldMonitor-Key: $WM_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_market_data","arguments":{}}}'
```

Send the key in `X-WorldMonitor-Key`, not as a bearer token; a key sent as a bearer returns `401 invalid_token`. If you hold an OAuth access token from `/api/oauth/token`, send `Authorization: Bearer $TOKEN` instead.
