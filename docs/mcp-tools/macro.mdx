### `get_economic_data`

Macro economic indicators: Fed Funds rate (FRED), economic calendar events, fuel prices, ECB FX rates, Bank of Russia official RUB rates and key policy rate, EU yield curve, earnings calendar, COT positioning, energy storage data, BIS household debt service ratio (DSR, quarterly, leading indicator of household financial stress across ~40 advanced economies), and BIS residential + commercial property price indices (real, quarterly).

**Parameters (tool-specific):**

| Name | Type | Description |
|------|------|-------------|
| `dataset` | `array<string: fedfunds / econ-calendar / china-macro / china-release-calendar / fuel-prices / ecb-fx-rates / cbr-rates / yield-curve-eu / spending / earnings-calendar / cot / dsr / property-residential / property-commercial>` | Restrict the response to one or more sub-datasets. Omit for the full economic bundle. |
| `country` | string | Country to filter the country-keyed datasets (fuel-prices, BIS DSR/property, economic and China release calendars) to, as an ISO 3166-1 alpha-2 or alpha-3 code or a country name. china-macro is returned as null unless the country is China. Unresolved inputs return Invalid params. |
| `limit` | number | Cap each list dataset (calendar, spending, earnings) to at most this many items (default 30, pass 0 for no cap). |

- **API endpoints:** `GET /api/economic/v1/get-china-macro-snapshot`, `GET /api/economic/v1/get-ecb-fx-rates`, `GET /api/economic/v1/get-economic-calendar`, `GET /api/economic/v1/get-eu-yield-curve`, `GET /api/economic/v1/list-fuel-prices`, `GET /api/market/v1/get-cot-positioning`, `GET /api/market/v1/list-earnings-calendar`
- **Access:** `free-account` — callable by any signed-in account; free accounts spend the daily free allowance, Pro calls spend the daily quota. Accepts the universal `summary` argument.
- **Kind:** cache read — sub-second response from Redis bootstrap cache.
- **Freshness budget:** up to **1 d** before `stale: true` is flagged (set by the seeder cron's expected interval).
- **Per-dataset caveat:** the single `stale` flag is derived from a subset of these sub-datasets, so it is not a per-dataset guarantee. `cbr-rates` is not one of them — it is published daily on a 3-day staleness budget with a 14-day content-age contract, both monitored on `/api/health` rather than through this flag. Read `cbr-rates.effectiveDate` when the age of that dataset specifically matters.

<CodeGroup>

```bash curl
curl -s https://worldmonitor.app/mcp \
  -H "X-WorldMonitor-Key: $WM_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "jsonrpc":"2.0","id":1,
    "method":"tools/call",
    "params":{"name":"get_economic_data","arguments":{}}
  }'
```

</CodeGroup>


### `get_fred_series`

**Access:** `subscription`.

Read up to 20 macroeconomic series from the same seeded cache and allowlist used by the dashboard. Calls the canonical `POST /api/economic/v1/get-fred-series-batch` RPC; it never calls FRED at request time. The live `series_ids` description lists all supported IDs, including `UNRATE`, `CPIAUCSL`, and `FEDFUNDS`.

**Parameters (tool-specific):**

| Name | Type | Description |
| --- | --- | --- |
| `series_ids` | `array<string>` | Required FRED IDs, normalized to uppercase. Up to 20 are forwarded. Unlisted IDs are ignored by the canonical reader. |
| `limit` | integer | Observations per series, newest-last. Default 24; valid range 1–1000. |

Returns `results` keyed by series ID, with title, units, frequency and observations. `requested` counts the unique allowlisted IDs looked up; `fetched` counts the ones present in cache. Missing seeded data remains missing; this call does not trigger a refresh. Large responses may be compacted by the MCP output budget.

Example: `get_fred_series({"series_ids":["UNRATE","CPIAUCSL"],"limit":24})`.

### `get_country_macro`

Per-country macroeconomic indicators from IMF WEO (~210 countries, monthly cadence). Bundles fiscal/external balance (inflation, current account, gov revenue/expenditure/primary balance, CPI), growth & per-capita (real GDP growth, GDP/capita USD & PPP, savings & investment rates, savings-investment gap), labor & demographics (unemployment, population), and external trade (current account USD, import/export volume % changes). Latest available year per series. Use for country-level economic screening, peer benchmarking, and stagflation/imbalance flags. NOTE: export/import LEVELS in USD (exportsUsd, importsUsd, tradeBalanceUsd) are returned as null — WEO retracted broad coverage for BX/BM indicators in 2026-04; use currentAccountUsd or volume changes (import/exportVolumePctChg) instead.

**Parameters (tool-specific):**

| Name | Type | Description |
|------|------|-------------|
| `countries` | `array<string>` | Countries to keep across all four IMF datasets, as ISO 3166-1 alpha-2 or alpha-3 codes or country names (e.g. ["US","DEU","China"]). Omit for all ~210 countries. Unresolved inputs return Invalid params. |
| `limit` | integer | Country entries to return per IMF dataset when countries is omitted; ignored when countries is set. Omitted returns 30; 0 returns every country. |

- **API endpoints:** none directly — reads from a bootstrap-aggregate cache key (no 1:1 REST endpoint).
- **Access:** `free-account` — callable by any signed-in account; free accounts spend the daily free allowance, Pro calls spend the daily quota. Accepts the universal `summary` argument.
- **Kind:** cache read — sub-second response from Redis bootstrap cache.
- **Freshness budget:** up to **70 d** before `stale: true` is flagged (set by the seeder cron's expected interval).

  -H "X-WorldMonitor-Key: $WM_KEY" \

### `get_price_and_debt_indicators`

Return the seeded price and debt indicator bundle: the Economist Big Mac index by country, the FAO Food Price Index and per-country national debt levels. Each sub-dataset has its own staleness budget (Big Mac a week, FAO and debt 60 days). No tariff rates. Seeded-cache read with no live fetch: weight 1 on API plans, included in the signed-in free allowance.

Formerly `get_tariff_trends`. A call to that old name with only the tariffs dataset runs `get_tariff_averages` and returns the US MFN series. Any other dataset on the old name still returns this bundle. This bundle has carried no tariff series since #9301. The US MFN series is Pro data. Call `get_tariff_averages` with reporter `840` and no partner or product group. `dataset: ["tariffs"]` on this tool returns Invalid params.

**Parameters (tool-specific):**

| Name | Type | Description |
|------|------|-------------|
| `dataset` | `array<string: bigmac / fao-ffpi / national-debt>` | Sub-datasets to return: bigmac (Economist Big Mac prices by country), fao-ffpi (FAO Food Price Index) or national-debt (debt by country). Omit for all three. |
| `country` | string | Country to filter the per-country datasets (Big Mac prices, national debt) to, as an ISO 3166-1 alpha-2 or alpha-3 code or a country name (e.g. "US", "USA", "United States"). Unresolved inputs return Invalid params. |
| `limit` | number | Cap each list dataset (BigMac countries, debt entries) to at most this many items (default 30, pass 0 for no cap). |

- **API endpoints:** `GET /api/economic/v1/get-fao-food-price-index`, `GET /api/economic/v1/get-national-debt`, `GET /api/economic/v1/list-bigmac-prices`
- **Access:** `free-account` — callable by any signed-in account; free accounts spend the daily free allowance, Pro calls spend the daily quota. Accepts the universal `summary` argument.
- **Kind:** cache read — sub-second response from Redis bootstrap cache.
- **Freshness budget:** per sub-dataset — BigMac **7 d**, FAO FFPI and national debt **60 d** each. The single `stale` flag ORs all three checks: it flips as soon as any one sub-dataset exceeds its own budget.

### `get_capital_flows`

Return where money enters and leaves about 230 economies, and between any two, from official statistics. IMF balance of payments: gross inflows and outflows split into FDI, portfolio and other investment, quarterly or annual by country, with derived Forbes-Warnock states (surge or stop for inflows, flight or retrenchment for outflows) and z-scores. Per country and per pair: BIS cross-border bank deposits and lending, IMF portfolio holdings and IMF direct-investment positions. People changing residence are not a BOP flow. Sources lag 1-3 quarters (FDI ~2 years); stale after 10 days or when the newest BOP quarter is over a year old. Seeded-cache read: weight 1 on API plans, included in the signed-in free allowance. country returns full views; counterpart adds both directions of each pair, each leg marked reported, not_itemized or not_published. Without country, a ranking of countries that have the sort metric (annual-only series have none).

Works for any economy and any pair: pass several `country` values to compare, add `counterpart` for bilateral detail, or omit `country` to rank the economies that have the chosen `sort` metric (the default `outflow_z` leaves out annual-only series, which have no z-score). Episode labels follow Forbes and Warnock (2012) and are derived from the reported flows. See [Capital Flows methodology](/methodology/capital-flows) for every view, leg and status.

**Parameters (tool-specific):**

| Name | Type | Description |
|------|------|-------------|
| `country` | `array<string>` | Countries to return in full: ISO 3166-1 alpha-2 (e.g. "GB"), alpha-3 ("ARE") or English names. Omit to get the cross-country ranking. |
| `include_series` | boolean | With country, also return the period-by-period BOP flows (12 quarters or 6 years). Default false. |
| `counterpart` | string | With country, a partner country (alpha-2, alpha-3 or name). Returns pairs[]: deposits each side's non-banks hold in the other's banks and bank lending each way (stock, 4-quarter flow, 8 quarters of history), each side's holdings of the other's securities, and direct investment each way with both sides' figures, plus the counterpart's own view. |
| `sort` | `string: outflow_z / inflow_z / outflows_pct_gdp / inflows_pct_gdp / net_usd_bn / bank_deposits_abroad_flow_4q / foreign_portfolio_change_pct` | Ranking field when country is omitted. outflow_z / inflow_z rank the latest Forbes-Warnock z-score; *_pct_gdp rank trailing gross flows as a share of GDP; net_usd_bn ranks inflows minus outflows; bank_deposits_abroad_flow_4q ranks the 4-quarter change in non-bank deposits held in foreign banks; foreign_portfolio_change_pct ranks the year-on-year change in foreign holdings of the country's securities. Default outflow_z. |
| `ascending` | boolean | Sort ascending instead of descending. Default false. |
| `limit` | number | Cap the ranking to this many countries (default 30, pass 0 for no cap). Ignored with country. |

- **API endpoints:** `GET /api/economic/v1/get-capital-flows`
- **Access:** `free-account` — callable by any signed-in account; free accounts spend the daily free allowance, Pro calls spend the daily quota. Accepts the universal `summary` argument.
- **Kind:** cache read — sub-second response from Redis.
- **Freshness budget:** **10 d** since the last weekly seed, plus a content-age check: `stale` flips when the newest IMF BOP quarter is more than 12 months old.

<CodeGroup>

```bash curl
curl -s https://worldmonitor.app/mcp \
  -H "X-WorldMonitor-Key: $WM_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "jsonrpc":"2.0","id":1,
    "method":"tools/call",
    "params":{"name":"get_capital_flows","arguments":{"country":["DE"],"counterpart":"JP"}}
  }'
```

</CodeGroup>
