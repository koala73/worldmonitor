Checkout: `a clean checkout of origin/main` at `d49477575b` (origin/main). Read-only.
Scope: `server/_shared/`, `server/worldmonitor/**`, `api/*.js`, `api/**/*.ts`, `convex/`.
Credential column: env var name, then `+` = present in `.env.local` (names only), `-` = absent.
"Relay" = Railway `ais-relay` service (`scripts/ais-relay.cjs`), reached via `WS_RELAY_URL` (-) + `RELAY_SHARED_SECRET` (+) (`server/_shared/relay.ts`, `api/_relay.js:9-18`).

## Method and the main finding

I grepped every `fetch(` / `fetchJson(` / `https://` call site in scope (157 files) and dropped calls to Redis REST, Convex, Axiom, Resend, Clerk, Dodo, Turnstile, DNS, and other ops or auth hosts. Most `server/worldmonitor/**` list handlers read only seeded Redis keys. Examples: `list-earthquakes.ts:15`, `list-unrest-events.ts:17`, `list-acled-events.ts:11`, `search-gdelt-documents.ts:13-16`, `get-pizzint-status.ts:11-12`, `list-prediction-markets.ts:20-21`. Those belong in the seeder inventory. The rows below are the handlers that contact an upstream themselves.

## Convex

**Crons** (`convex/crons.ts`): none of them fetches a data feed. All are ops jobs:
- pairing-token cleanup
- API plan-limit scan: the one external fetch, an Axiom APL query (`convex/apiPlanLimitUsage.ts:54,236`) over `wm_api_usage` (usage telemetry, not world data)
- plan-limit emails
- account-deletion and company-monitoring reapers and reconcilers
- user-prefs prune
- api-plan-limit prune (90 d, `apiPlanLimitNotices.ts:562`)
- `intel-history-prune` (daily 04:30 UTC)
- broadcast ramp and wave cleanup
- payments reconciliation every 6 h, plus dunning, renewal, and business grants
- followed-countries shard and lock seeding

Other Convex actions that fetch externally call only Resend, Dodo, Clerk, Upstash, or Axiom.

**Tables holding time-series or historical records** (`convex/schema.ts`):
- **`intelHistory`** (`schema.ts:1877-1914`): append-only event memory. Fields: domain, resource, country, category, title, summary, sourceUrl, occurredAt, ingestedAt, runId, dedupeKey, plus a 512-d embedding with a vector index. Retention is **180 days by ingestedAt** (`convex/intelHistory.ts:68-70`), pruned daily. Today's producers are seeders only, domains "conflict" | "military" | "energy" (`scripts/seed-conflict-intel.mjs`, `seed-energy-intelligence.mjs`, `seed-cross-strait-activity.mjs` via `scripts/_seed-history.mjs`). `intelHistoryRetractions` tombstones live for 180 d (`schema.ts:1927`). This is the existing seed of a memory lake.
- `companyMonitoringEvidence`, `companyMonitoringXEvidence` (`schema.ts:1403,1450`): per-customer evidence from Exa and X with publishedAt/observedAt and optional expiresAt. The producer is `scripts/company-monitoring-worker.mjs`. The data is customer-scoped, so do not use it for global learning without a policy decision.
- `apiUsageRollups` (`schema.ts:863`) and `apiPlanLimitNotices`: product usage, 90-d prune.
- Everything else is user, billing, or broadcast state.
