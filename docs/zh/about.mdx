World Monitor 是一个免费、开源（AGPL-3.0）的实时全球情报仪表盘。它把世界的原始信号——船舶、飞机、卫星、警报、海底电缆、市场，以及经过来源标注的新闻与 OSINT 信息——汇聚到一张实时地图上，并在信号相互印证、形成真正重要的事件时发出提示。[超过 200 万用户](https://siliconcanals.com/sc-n-anghami-ceos-side-project-world-monitor-now-has-2-million-users-tracking-conflicts-in-real-time/)遍布 190+ 个国家，无需账户，也没有试用期限。

每个数字都有出处，每种方法都有文档。等到它成为新闻时，你早已知晓。

## 工作方式

World Monitor 没有新闻编辑室，也没有人工编辑。它依靠方法论。

- **聚合胜于噪声。** 信号在浮现为警报之前，会与多个独立来源交叉核对。突发横幅必须通过严重度、时效与佐证的固定门槛，因此单一未经证实的报道不会变成头条。
- **分级的来源层级。** 通讯社和官方渠道高于主要广播机构，后者又高于专业开源情报机构，并始终保留来源溯源。每个面板都会内联标注来源与时间戳。
- **国家档案。** 点击任意国家，即可查看其不稳定评分及构成、带引用的 AI 简报、地图上的活跃信号以及 7 天时间线，并附有结构韧性排名。
- **有记录可查的预测。** 公开的 AI 预测附带概率、置信度与时间范围，[公开记分卡](https://www.worldmonitor.app/accuracy/)记录其最终结果。
- **AI 是叠加，而非替代。** 简报、风险评分与预测都由底层信号生成，而非出自聊天机器人的臆想。

它可以在你工作的任何地方运行：

- **网页**：[worldmonitor.app](https://www.worldmonitor.app/dashboard)，也可安装为支持离线地图瓦片的 PWA
- **桌面**：适用于 Windows、macOS（Apple Silicon 与 Intel）和 Linux 的[原生应用](https://github.com/koala73/worldmonitor/releases/latest)，使用操作系统钥匙串存储密钥，并带有本地 API 边车

- **Android TV**：用于大屏展示
- **自托管**：通过 [Docker 或 Vercel](/zh/getting-started) 部署，可借助 Ollama 使用本地 AI

全部界面均已本地化，并为阿拉伯语和波斯语提供从右到左的布局。

## 为智能体而建

地图上的一切同样是 API。你的代码用实时数据做研究，而不是依赖训练数据中的记忆。

- **[MCP 服务器](https://worldmonitor.app/mcp)**：完整的实时工具目录、Streamable HTTP、OAuth 或 API 密钥，每次调用都支持 JMESPath 投影
- **[REST API](/zh/api-reference)**：统一的 OpenAPI 3.1 规范，一个密钥
- **[官方 SDK](/zh/sdks)**：Python、JavaScript、Ruby 与 Go，零依赖
- **[CLI](/zh/cli)**：在 shell 或流水线中调用任意工具
- **签名 Webhook**：咽喉要道中断、国家风险激增、突发新闻、市场异动与自然灾害
- **[智能体技能](https://www.worldmonitor.app/agent/)**：适用于 Claude、ChatGPT、Cursor 及任何 MCP 客户端

## 免费版是观测站，Pro 是作战室

免费仪表盘是完整的产品，而非试用：除结构韧性外的全部地图图层、全部六个监测台、国家简报、咽喉要道、级联分析、突发警报流程与关注列表。

**[World Monitor Pro](https://www.worldmonitor.app/pro)** 起价每月 $39.99，增加决策层：

- **WM Analyst**：跨实时服务、带引用的 AI 分析师
- **Scenario Engine**（每小时运行）与 **Route Explorer**
- **成本冲击与供应链压力测试**：覆盖咽喉要道、级联与脆弱性排名
- **警报规则**：按国家、事件类型、严重度与咽喉要道设置，推送到 Slack、Microsoft Teams、Discord、Telegram、电子邮件、推送通知或签名 Webhook
- **个人 AI 摘要**：每日、每日两次或每周
- **情报记忆**：历史检索与相似事件查找
- **自定义组件构建器**与**结构韧性**地图图层
- **MCP 访问**：通过 OAuth 连接 Claude、ChatGPT 等 AI 客户端

Pro Business 增加商业许可与数据导出。API 套餐增加 REST 与 SDK 密钥、调用配额和 Webhook，API Business 另含再分发权。Enterprise 增加 SSO、团队工作区、白标面板以及本地或隔离网络部署。参见[定价](https://www.worldmonitor.app/pro#pricing)与[许可范围](/zh/eula)。

## 起源

{/* Traction: 2M+ 用户引自 Silicon Canals；国家覆盖与首页/llms.txt 一致（190+）；GitHub 星标通过 shields.io（GitHub API）实时渲染。 */}

World Monitor 始于 2026 年 1 月的一个周末项目。Elie Habib——音乐流媒体平台 Anghami 的联合创始人兼 CEO——在短短几天内构建了第一个版本，以验证能否将一天纷乱的地缘政治新闻在一张地图上呈现得清晰易读。他公开发布了一次，随后便将注意力转向别处。

但它并未就此沉寂。随着 2026 年全球局势不断升级，该仪表盘在第一周就触达了数十万用户，此后更增长到遍布 [190+ 个国家的 200 万+ 用户](https://siliconcanals.com/sc-n-anghami-ceos-side-project-world-monitor-now-has-2-million-users-tracking-conflicts-in-real-time/)——其中大多数人远非通常的情报工具用户群体。如今它已是 GitHub 上星标最多的开源 OSINT 项目之一（[![GitHub Repo stars](https://img.shields.io/github/stars/koala73/worldmonitor)](https://github.com/koala73/worldmonitor/stargazers)）。

## 使命

了解世界的态势感知不应需要一台五位数价格的终端。World Monitor 的目标是让可信的实时全球情报——那种通常只为政府、基金和新闻编辑室保留的情报——人人只需一个浏览器即可获取，任何持有密钥的 AI 智能体也同样可以使用。

## 由谁打造

World Monitor 由 [Elie Habib](https://x.com/eliehabib) 打造，他是 Anghami 的联合创始人兼 CEO——Anghami 是首家在纳斯达克上市的阿拉伯科技公司。该平台以 AGPL-3.0-only 开源，参见[许可证](/zh/license)和[商标政策](/zh/trademark-policy)。官方维护的代码仓库是 [github.com/koala73/worldmonitor](https://github.com/koala73/worldmonitor)；其他副本与名称相近的产品均[与本项目无关](https://www.worldmonitor.app/world-monitor.md)。
