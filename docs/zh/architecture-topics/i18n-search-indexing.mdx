## 国际化与搜索索引

World Monitor 对仪表盘与 Pro 页面使用**应用本地化**，对欢迎页使用**可被索引的本地化文档**。
`?lang=` 参数仍作为 `/`、`/dashboard` 和 `/pro` 上可分享的用户偏好状态：客户端加载所请求的界面词典，
更新渲染文档的语言与方向，并保留基础页面的规范链接。带查询字符串的语言 URL 不属于 hreflang、
robots 或站点地图输出。

主域欢迎页还提供预渲染的落地页：`/es/`、`/pt/`、`/ru/`、`/fr/`、`/de/` 和 `/ar/`。这些 URL 返回 HTTP 200 的 HTML，
带有已翻译的可见文案与元数据。不存在基于 Accept-Language 的重定向：爬虫和直接访问都会收到本地化文档。
语言集合定义在 `shared/indexable-landing-locales.ts`。

**各页面类型的 hreflang 策略：**

| 页面类型 | 可索引语言 | 声明方式 |
| --- | --- | --- |
| 主域 `/` 与本地化欢迎落地页（`/es/`、`/pt/`、`/ru/`、`/fr/`、`/de/`、`/ar/`） | 英语加上述语言 | 互相指向的集群；`x-default` 为英文 `/` |
| `/dashboard`、`/pro` 以及英文可抓取语料页（`/countries/`、`/chokepoints/` 等） | 仅英语 | 指向自身的 `en` + `x-default` |
| Mintlify 文档（`/docs/…` 与 `/docs/zh/…`） | 英语 + 简体中文 | 互相指向的 `en` / `zh-Hans` / `x-default`（英文为 `x-default`） |
| 通过 `?lang=` 切换的应用界面 | 不作为可索引的替代版本 | 绝不写入 hreflang |

每个对外声明的落地页都必须满足完整的本地化页面约定：

- 已翻译的可见主体内容与元数据；
- 正确的 `<html lang>` 声明；
- 稳定、可抓取、返回 HTTP 200 且保持可索引的 URL；
- 指向自身的规范链接；
- 集群内指向自身且互相指向的 hreflang 条目；以及
- 本地化规范 URL 已收录于站点地图，落地页集群带有 xhtml:link 替代链接。

真正本地化的页面不得将规范链接指回英文。新增客户端翻译或受支持的语言代码，
并不意味着可以发布新的可索引替代版本，除非该语言已加入落地页注册表并完成预渲染。
