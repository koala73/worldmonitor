本页是[数据源](/zh/data-sources)的合规配套页。数据源页面说明 World Monitor **覆盖什么**、每个领域由**哪些**提供方支撑；本页则是原始的、机器审计的台账：源代码树中观测到的每一个上游主机、它的接口类型(结构化 API、订阅源或运行状态端点)、我们记录的许可状态,以及所需的署名。

该清单是**生成的,而非手写的**:`scripts/source-attribution.mjs` 扫描 `scripts/`、`server/`、`api/` 与 `src/` 中的 URL 字面量,并与提交的清单文件(`shared/source-attribution-manifest.json`)进行比对。代码中出现但清单中缺失的主机会导致 CI 失败,因此该披露不会与代码实际抓取的内容悄然脱节。状态含义:

| 状态 | 含义 |
|------|------|
| `reviewed` | 许可与署名条款已经审查;所列署名要求为权威结论。 |
| `terms-review` | 主机处于活跃状态,但其条款尚未逐项审查——在任何再分发或商业使用声明前请先确认。 |
| `excluded` | 在代码中观测到,但不是被摄取的数据集(第一方传输、仅用于展示的流媒体、控制面)——不计入提供方统计。 |

## 观测到的上游清单

完整的逐主机清单表(500 余行,含每个主机的代码引用位置)由生成器维护在[英文来源署名页](/source-attribution#observed-upstream-inventory)上,并随每次代码变更自动重新生成。中文页面不镜像该生成表格,以避免出现过期的人工翻译副本;各领域的主要提供方及其数据说明请见[数据源](/zh/data-sources)。
