World Monitor 从单一代码库运行六个专用变体，每个变体针对不同的监控需求进行了优化。

## 平台变体

| 变体 | URL | 关注方向 |
|---------|-----|-------|
| **🌍 World Monitor** | [worldmonitor.app](https://www.worldmonitor.app) | 地缘政治情报、军事追踪、冲突监测、基础设施安全 |
| **💻 Tech Monitor** | [tech.worldmonitor.app](https://tech.worldmonitor.app/dashboard) | 科技行业情报、AI/初创企业生态、云基础设施、科技事件 |

| **💰 Finance Monitor** | [finance.worldmonitor.app](https://finance.worldmonitor.app/dashboard) | 全球市场、证券交易所、央行、大宗商品、外汇、加密货币、经济指标 |

## World Monitor（地缘政治）

主变体聚焦于地缘政治情报、军事追踪和基础设施安全监测。

### 核心能力

- **冲突监测** - 实时追踪活跃战区、热点地区和危机区域的升级动态
- **军事情报** - 已注册军事基地、航班追踪、海军船舶监测、兵力集结检测
- **基础设施安全** - 海底电缆、管道、数据中心、网络中断
- **经济情报** - FRED 指标、石油分析、政府支出、制裁追踪
- **自然灾害** - 地震、恶劣天气、NASA EONET 事件（野火、火山、洪水）
- **AI 驱动分析** - 焦点检测（AI 检测到的新闻聚合区域，有别于静态情报热点）、国家不稳定性评分、基础设施级联分析

### 情报面板

| 面板 | 用途 |
|-------|---------|
| **AI Insights** | LLM 综合世界简报，含焦点检测 |
| **AI Strategic Posture** | 战区级军事力量聚合，含打击能力评估 |
| **Country Instability Index** | 31 个一级国家的实时 CII v14 稳定性评分及带符号的 24 小时变动增量 |
| **Strategic Risk Overview** | 综合所有情报模块的综合风险评分 |
| **Infrastructure Cascade** | 电缆、管道和咽喉要道的依赖分析 |
| **Live Intelligence** | 基于 GDELT 的主题信息流（军事、网络、核、制裁） |
| **Metals & Materials** | 来自 Yahoo Finance 的金属与原材料报价；有数据时提供实物溢价和欧元汇率标签页。以其他货币计价的黄金标签页仅在大宗商品变体中显示。能源价格改在 Energy Complex 面板中显示 |
| **Toronto Safety** | 多伦多警察局开放数据：已报告的重大犯罪事件（位置经过近似偏移）以及按分局和社区统计的年度出警次数。非实时调度数据。默认关闭 |
| **Global Giving** | 来自平台和机构（GoFundMe、GlobalGiving、JustGiving、Candid、OECD）的已发布捐赠基准，附来源期间和核实状态。年化数字为估算值，非实时活动。此处默认关闭；在 Happy 变体中默认开启 |

### 新闻覆盖

涵盖地缘政治、国防、能源、智库和区域新闻（中东、非洲、拉丁美洲、亚太）的精选新闻源。

## Energy Monitor

能源变体（[energy.worldmonitor.app](https://energy.worldmonitor.app/dashboard)）聚焦油气基础设施、供应中断和能源冲击。

### 能源图层

| 图层 | 描述 |
|-------|-------------|
| **Live Tanker Positions** | 霍尔木兹、苏伊士、曼德海峡、马六甲、巴拿马和博斯普鲁斯约 2° 范围内油轮的实时 AIS 位置。琥珀色为锚泊，青色为航行中，灰色为无航速报告。图层开启时每 60 秒轮询一次 |
| **Pipelines** | 来自有证据支撑的注册表的油气管道，按状态着色（flowing、reduced、offline、disputed）。在平面地图上，选择一条管道会打开 Pipeline Status 抽屉 |
| **Storage Facilities** | 来自 Storage Atlas 注册表的地下储气库、战略储备、LNG 接收站和原油枢纽 |
| **Fuel Shortages** | 来自 Fuel Shortage Registry、存在已确认或观察级燃料短缺的国家 |
| **Commodity Ports** | 矿产进出口港口和码头 |

### 能源面板

这些面板背后的资产注册表整理自运营商披露、监管机构文件和公开数据集。每个状态徽章都由一组证据推导而来，选择一行或平面地图上的一个标记即可打开包含这些证据的抽屉。方法论：[管道](/zh/methodology/pipelines)、[储存](/zh/methodology/storage)、[燃料短缺](/zh/methodology/shortages)、[中断](/zh/methodology/disruptions)。

| 面板 | 描述 |
|-------|-------------|
| **Global Energy Risk Overview** | 一排指标卡：霍尔木兹通行状态、欧盟天然气储存充盈率、布伦特价格及日变化、进行中的中断数量、数据新鲜度，以及危机天数计数。每张卡独立加载，来源失败时显示“—” |
| **Oil & Gas Pipeline Status** | 资产、路线、输量和状态徽章（flowing、reduced、offline 或 disputed）。抽屉显示证据、制裁引用和该资产的中断时间线 |
| **Strategic Storage Atlas** | 地下储气库、战略石油储备洞穴、LNG 接收站和储罐区，含国家、类型、容量和状态 |
| **Global Fuel Shortage Registry** | 国家与油品、开始日期、证据，以及严重程度徽章：confirmed（红色）或 watch（琥珀色）。已确认的短缺排在前面 |
| **Energy Disruptions Log** | 管道和储存设施的停运事件，可按原因（破坏、制裁、机械、维护、战争、天气、商业）筛选，并可只看进行中的事件。选择一个事件会打开受影响资产的抽屉 |
| **GCC Energy Investments** | 即上文“金融面板”中介绍的海湾投资登记 |

Global Energy Risk Overview 仅在能源变体中默认开启。其余四个能源面板在地缘政治变体中也默认开启。
