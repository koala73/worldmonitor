## 平台评估指南

本节为采购、安全和工程团队简要说明当前平台。各变体的详细说明见后文。

### 技术能力

World Monitor 将交互式 3D 地球仪和平面地图、可配置情报面板、带来源归属的新闻与 OSINT、市场和经济数据、国家风险与韧性评分、基础设施与供应链分析、情景建模、AI 生成简报及告警工作流整合在一起。生成的产品清单记录共享地图图层目录、具体面板实现和专用产品变体。

| 能力 | 当前范围 |
| --- | --- |
| 国家风险与韧性 | 国家不稳定性指数（CII v8）为 31 个一级国家提供评分和带符号的 24 小时变化。国家韧性指数使用 72 个指标，按 21 个有效维度和 6 个领域对 196 个国家的公开范围进行排名，每 6 小时运行一次。 |
| 信号与基础设施分析 | 地理汇聚、时间异常和跨来源关联功能会组合相关事件。基础设施级联功能对包含 350 个节点的基础设施图进行依赖关系建模。 |
| 决策支持 | 带来源链接的 AI 简报、含机器可检查解决标准和评分卡上下文的概率预测、[路线探索器](/zh/route-explorer)及[情景引擎](/zh/scenario-engine)。 |
| 公司与采购工作流 | MCP 公司情报工具组合市场上下文、SEC 文件搜索和重大 8-K 事件。[全球采购情报](/zh/global-procurement-intelligence)使用来自支持的政府和多边机构门户的种子化公开机会。可用性仍取决于部署凭据和来源健康状态。 |
| 交付界面 | 托管 Web 仪表盘和可安装 PWA、适用于 macOS、Windows 和 Linux 的原生桌面应用，以及自托管技术栈。桌面应用包含本地 Node.js 边车，并支持 Ollama 和 LM Studio 等本地 LLM 端点。 |
| 语言覆盖 | 界面提供本地化和从右到左布局。阿拉伯语和波斯语使用从右到左布局。本站文档目前提供英语和简体中文。 |

完整产品功能见[功能与界面](/zh/features)。处理模型、缓存、韧性控制和部署组件见[架构](/zh/architecture)。方法论页面说明平台如何计算[算法与复合信号](/zh/algorithms)。

### 更新频率与新鲜度

World Monitor 不对所有数据集使用统一刷新间隔。每个来源的更新节奏与其上游提供方发布有效观测值的频率相匹配。快速变化的数据流使用实时或分钟级管道；机构数据则保持其每日、每周或每月发布周期。

以下周期对应特定产品界面。REST 和 MCP 的新鲜度预算可能与仪表盘轮询间隔不同。

| 数据领域 | 正常产品周期 | 重要说明 |
| --- | --- | --- |
| 海事追踪 | 启用后，AIS 使用实时 WebSocket；快照界面约每 5–15 分钟刷新 | MCP 实时通行摘要使用 30 分钟新鲜度预算。PortWatch 衍生产品较慢，预算为 12–36 小时，来源值可能按周更新。 |
| 航空 | 实时军用航班和机场运营界面约每 2–5 分钟刷新 | 其他航班数据流取决于提供方；基于航班的 MCP 工具使用 30 分钟新鲜度预算。 |
| 市场数据 | 仪表盘每 12 分钟刷新市场报价 | MCP 市场数据使用 30 分钟新鲜度预算。CFTC、FRED 和其他机构序列遵循各自发布周期。 |
| 仪表盘新闻与 OSINT | 仪表盘每 20 分钟刷新 | 发布方时间各不相同。如果没有新内容，刷新可能返回同一篇最新文章。 |
| 冲突与动荡 | GDELT 批量物化每 15 分钟运行 | MCP 动荡数据在超过 2 小时后标记为过期。其他冲突来源保持各自周期。 |
| 国家韧性指数 | 每 6 小时运行 | 一次成功运行并不表示每个上游序列都发布了新值。 |
| 机构经济数据 | 每日、每周或每月 | BIS、Eurostat、IMF、世界银行及类似数据集保持其原生发布日历。 |

这些是运行目标，不保证上游发布方会在每个时间窗口内发布新观测值。支持该能力的缓存型 API 和 MCP 响应会提供时间戳与 `stale` 标记。各工具的新鲜度预算见 [MCP 工具参考](/zh/mcp-tools-reference)，监控语义见[健康端点](/zh/health-endpoints)，当前服务状态见 [status.worldmonitor.app](https://status.worldmonitor.app/)。

### 来源与溯源

World Monitor 发布了公开且可搜索的[数据源目录（英文）](https://worldmonitor.app/sources)。该目录基于来源归属清单生成，列出活跃提供方、上游主机、结构化端点以及新闻和 OSINT 数据流。应用数据流注册表与 Telegram 目录是独立的清单层级，不应相加。

在这些清单中，World Monitor 组合结构化 API、公开和授权数据集、政府及多边机构官方来源、新闻源和经过审核的 OSINT。代表性提供方包括 ACLED、UCDP、GDELT、UNHCR/OCHA、IMF、世界银行、BIS、Eurostat、FRED、USGS、NASA、Open-Meteo、Cloudflare Radar、AIS 与 ADS-B 提供方，以及数百家新闻发布机构。RSS 配置可包含来源层级、国家关联和宣传风险元数据。Telegram 配置使用不同的结构，包含层级、主题和地区元数据。跨来源佐证可以提高排序和置信度，但不是每个告警的通用前提条件。

请先使用公开的[数据源目录（英文）](https://worldmonitor.app/sources)，按信号领域、来源类型或来源国搜索和筛选提供方。有关收集方法、覆盖范围、可信度层级和偏见元数据，请查看[数据源方法论](/zh/data-sources)。有关主机级归属和条款审核状态，请查看机器生成的[来源归属清单](/zh/source-attribution)。生成检查会检测仓库漂移，但清单条目本身不构成法律许可。不同功能和部署模式的来源可用性与许可条件可能不同。

| --- | --- | --- |

| [REST API](/zh/api-reference) | 应用、数据管道和较高流量的批量读取 | OpenAPI 3.1 描述生成的服务合同和版本化 HTTP 路径。标准服务器到服务器访问通过 `X-WorldMonitor-Key` 发送 API 密钥。请在参考文档中检查当前路由状态，并查看[快速入门](/zh/usage-quickstart)、[身份验证](/zh/usage-auth)、[版本政策](/zh/api-versioning)和 [REST 速率限制](/zh/usage-rate-limits)。 |

| [官方 SDK](/zh/sdks) 与 [CLI](/zh/cli) | Python、Ruby、Go、JavaScript 应用或 Shell 自动化 | 对应语言运行时；数据调用需要 API 密钥。零依赖 SDK 和 npm CLI 支持托管及自托管基础 URL。 |
| [通知渠道](/zh/api-notifications) | 向运营系统发送通用领域告警 | 已计费的 PRO 账户和 Clerk bearer token。支持的交付渠道包括签名 HTTPS Webhook、Telegram、Slack、Discord、电子邮件和 Web Push。可用性取决于事件领域和渠道配置。 |
| [航运 Webhook](/zh/api-shipping-v2) | 咽喉要道中断通知 | 具备 PRO 权限的 API 密钥，以及通过文档所述 SSRF 检查的公开 HTTPS 回调。交付使用 HMAC-SHA256 签名，并采用至少一次语义。这些 Webhook 仅适用于特定领域，并非全平台通用事件总线。 |
| [智能体发现](/zh/agent-discovery) | 自动化接入和智能体原生工作流 | 标准 `.well-known` 元数据、`llms.txt`、OpenAPI 资产、MCP 服务器卡和可安装的智能体技能目录。发现元数据公开；携带数据的操作仍需要相应凭据。 |
| 自托管部署 | 需要自行运行整个技术栈的团队 | Node.js 22+、Docker 或 Podman、Redis、部署密钥，并遵守 [AGPL 或单独商业许可](/zh/license)。请参阅[入门指南](/zh/getting-started)。 |

浏览器内 API 调用请查看 [CORS 策略](/zh/cors)。生成客户端请使用机器可读合同：[OpenAPI 规范](https://www.worldmonitor.app/openapi.yaml)。

## World Monitor（地缘政治）

主变体聚焦于地缘政治情报、军事追踪和基础设施安全监测。

### 核心能力

- **冲突监测** - 实时追踪活跃战区、热点地区和危机区域的升级动态
- **军事情报** - 已注册军事基地、航班追踪、海军船舶监测、兵力集结检测
- **基础设施安全** - 海底电缆、管道、数据中心、网络中断
- **经济情报** - FRED 指标、石油分析、政府支出、制裁追踪
- **自然灾害** - 地震、恶劣天气、NASA EONET 事件（野火、火山、洪水）
- **AI 驱动分析** - 焦点检测（AI 检测到的新闻聚合区域，有别于静态情报热点）、国家不稳定性评分、基础设施级联分析

### 情报面板

| 面板 | 用途 |
|-------|---------|
| **AI Insights** | LLM 综合世界简报，含焦点检测 |
| **AI Strategic Posture** | 战区级军事力量聚合，含打击能力评估 |
| **Country Instability Index** | 31 个一级国家的实时 CII v8 稳定性评分及带符号的 24 小时变动增量 |
| **Strategic Risk Overview** | 综合所有情报模块的综合风险评分 |
| **Infrastructure Cascade** | 电缆、管道和咽喉要道的依赖分析 |
| **Live Intelligence** | 基于 GDELT 的主题信息流（军事、网络、核、制裁） |

### 新闻覆盖

涵盖地缘政治、国防、能源、智库和区域新闻（中东、非洲、拉丁美洲、亚太）的精选新闻源。
