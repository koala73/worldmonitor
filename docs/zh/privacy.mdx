本隐私政策说明在阿拉伯联合酋长国迪拜注册的自由区有限责任公司 World Monitor FZ LLC（“World Monitor”、“我们”）在您使用 World Monitor 仪表盘、网站、API、MCP 服务器和应用（“服务”）时如何处理信息。

本页面以通俗语言撰写，不构成法律意见。

## 简要版本

- 基础仪表盘**无需账户、无需注册**即可使用。
- 我们不出售您的个人数据。
- 我们使用一小组成熟的子处理方来处理身份验证、支付、托管、错误监控和 AI 分析——完整清单见下文。
- 您可随时请求访问、导出或删除您的账户数据。

## 我们收集的信息

**账户信息。** 如果您创建账户或升级到 Pro，我们的身份验证提供商（Clerk）会处理您的电子邮件地址、姓名和登录凭证。我们将账户标识符以及您的套餐/权益状态存储在我们的数据库（Convex）中。

**支付信息。** 订阅由 Dodo Payments 处理，其作为登记商户（merchant of record）。您的完整卡片信息由支付处理方录入并保管——**World Monitor 绝不接收或存储您的完整卡号。** 我们仅接收管理您订阅所需的有限计费元数据（例如套餐、状态、国家/地区和卡号后四位）。

**使用与诊断信息。** 为保持服务可靠，我们收集：

- **错误和崩溃诊断信息**，通过 Sentry 收集（例如错误消息、堆栈跟踪、浏览器和设备类型）。
- **注重隐私的产品分析数据**，通过 Vercel Web Analytics、Cloudflare 以及我们自托管的 Umami 实例（`abacus.worldmonitor.app`）收集——用于了解流量模式。它们的设计旨在避免跨站跟踪，并在相应配置下不使用 Cookie。对已登录用户，Umami 事件还会携带你的账户标识符、套餐和订阅状态，以便我们了解各套餐如何使用产品。
- **页面性能监测（RUM）**，通过 DebugBear 按 10% 的页面加载抽样收集。它接收页面路径、视口与设备像素比、导航与网页核心指标计时、用户代理，以及任何网络请求都必然包含的 IP 地址，另外还有抽样页面上出现的浏览器错误（错误消息、堆栈跟踪和源 URL）。**URL 查询参数不属于其页面数据** —— 你地址栏中携带的仪表盘状态（地图视图、时间范围、已选图层）不会随页面浏览一起存储。但浏览器错误报告仍可能包含带查询字符串的页面地址，因此这些仪表盘状态可能出现在错误数据中。当地址中含有登录令牌、结账或推荐代码、电子邮件参数时，DebugBear 不会加载。用途是发现缓慢和不稳定的页面，而非识别或追踪你。
- **服务器和请求日志**，通过 Axiom 及我们的托管/CDN 提供商（Vercel、Cloudflare）收集，包括 IP 地址、用户代理和请求元数据，为安全和调试目的而保留。

**您提交给 AI 功能的内容。** 当您使用 AI 简报、分析、预测或研究助手时，您的查询文本和相关上下文会被发送给我们的 AI 提供商（Anthropic，以及通过 OpenRouter 接入的其他模型提供商）以生成响应。请勿在 AI 提示词中提交敏感个人数据。

**偏好设置与警报。** 诸如已保存位置、警报规则和图层偏好等设置存储在您的浏览器（local storage）中，对于已登录用户，也存储在我们的数据库（Convex）中。

## Cookie 与本地存储

- **必要项**——身份验证会话（Clerk）和安全功能使用 Cookie 或等效存储，这些是已登录功能正常工作所必需的。
- **偏好项**——仪表盘设置本地存储在您的浏览器中。
- **分析项**——我们的分析功能设计上注重隐私，并在相应配置下不使用跟踪 Cookie。

## 子处理方

我们仅与下列代表我们处理数据以运营服务的服务提供商共享个人数据。每一行都写明了该提供商会接收哪些个人数据。下表同时列出了我们自行托管的那一个分析采集器，以便你把网络请求日志中看到的内容与本表逐一对应。

| 提供商 | 用途 | 处理的个人数据 |
|----------|---------|----------------------------|
| Clerk | 身份验证和账户管理 | 姓名、电子邮件地址、登录凭证和会话令牌 |
| Convex | 应用数据库（账户、计费记录、权益、API 密钥、警报、偏好） | 账户标识符、姓名和电子邮件地址、订阅与付款记录（包括支付服务商的客户信息）、套餐与权益状态、API 密钥（以哈希形式存储）、警报规则及你连接的投递目标、已保存的偏好，以及你通过联系表单发送的消息 |
| Dodo Payments | 支付处理和订阅计费（登记商户） | 姓名、电子邮件地址、账单信息和银行卡信息（由 Dodo Payments 保管；我们仅收到套餐、状态、国家/地区和卡号后四位） |
| Sentry | 错误和崩溃监控 | 错误消息、堆栈跟踪、浏览器和设备类型，以及任何网络请求固有的 IP 地址 |
| DebugBear | 真实用户页面性能监测（10% 页面加载抽样） | 页面路径、视口、导航和 Web Vitals 时序、用户代理、IP 地址，以及抽样页面上的浏览器错误（错误消息、堆栈跟踪和源 URL） |
| Umami（自托管，`abacus.worldmonitor.app`） | 产品分析，运行在我们自己的 Railway 项目中 —— 没有分析服务商接收这些数据 | 页面浏览和产品事件，以及网络请求携带的浏览器和设备信息；对已登录用户，还包括你的账户标识符、套餐和订阅状态 |
| Upstash | 速率限制与缓存存储 | 由你的 IP 地址派生的速率限制键、缓存的权益记录和短期缓存的响应 |
| Railway | 我们后台服务的容器托管：警报与摘要投递、数据中继（包括小组件生成器），以及我们的 Umami 分析实例及其数据库 | 警报与摘要内容及其投递目标标识符、你发送给小组件生成器的提示词，以及存储在其数据库中的 Umami 分析事件（对已登录用户，包括你的账户标识符、套餐和订阅状态） |
| Mintlify | 文档站点托管（`worldmonitor.app/docs`，包括本页） | 文档页面请求的 IP 地址和用户代理 |
| Vercel | 应用与 API 托管，以及网页分析 | IP 地址、用户代理和请求元数据，以及传输中的 API 请求与响应内容 |
| Cloudflare | 内容分发、边缘安全、机器人验证（Turnstile）、网页分析和对象存储（R2） | IP 地址、用户代理、请求元数据和 Turnstile 验证信号 |
| Axiom | 应用日志和可观测性 | IP 地址及大致位置（城市、地区）、用户代理、来源页、请求元数据和你的账户标识符 |
| Anthropic | 用于分析、简报和小组件生成器的 AI 模型提供商 | 你的 AI 查询文本及随附的上下文 |
| OpenRouter | 用于分析和预测的 AI 模型路由；它会把每个请求转交给其路由到的模型提供商 | 你的 AI 查询文本及随附的上下文 |
| Resend | 事务性电子邮件投递 | 收件人电子邮件地址和邮件内容 |

在新的子处理方开始处理个人数据之前，我们会至少提前 30 天发出通知，具体见[数据处理附录](/zh/dpa)中的“次级处理方”条款（具有约束力的英文版第 8 节）。

## 你的告警发送到哪里

如果你连接了告警或摘要渠道，我们会把你所请求的告警内容发送到**你**选择的目的地：Telegram、Slack、Discord、你自己的 Webhook URL、电子邮件，或浏览器推送端点。为此我们会存储该渠道所需的标识信息 —— 聊天或频道 ID、Webhook URL，或你授予我们的 OAuth 令牌 —— 除此之外不存储其他内容。

这些目的地不是我们的次级处理方：它们接收你的告警是因为你如此指示，其对内容的处理受你与它们自身关系的约束。断开某个渠道即会删除我们为其保存的标识信息。

## 我们如何使用信息

我们使用上述信息来运营和保护服务、验证用户身份、处理订阅、生成您请求的 AI 分析、就您的账户与您沟通，以及改进可靠性和性能。我们以正当利益、合同履行，以及在适用情况下您的同意作为此类处理的法律依据。

## 数据保留

只要您的账户处于活跃状态，以及为履行法律、税务和安全义务所需，我们就会保留账户和订阅数据。诊断和日志数据以滚动方式保留有限的一段时间。当您删除账户时，我们会删除或匿名化相关的个人数据，法律要求我们保留的情形除外。

## 您的权利

根据您所在地区的法律（包括欧盟/英国 GDPR 以及加利福尼亚州 CCPA/CPRA），您可能有权访问、更正、导出或删除您的个人数据，并有权反对或限制某些处理活动。已登录用户可在 **头像 → Plan & billing → Delete account** 输入 `DELETE` 自行删除账户；详见[账户](/zh/accounts)。如果无法登录，请使用账户邮箱写信至 [support@worldmonitor.app](mailto:support@worldmonitor.app)，以便我们确认 Clerk 用户 id。匿名使用仪表盘时没有服务器账户 — 请清除本地站点数据。要行使上述任何权利，请通过 [support@worldmonitor.app](mailto:support@worldmonitor.app) 联系我们。您还有权向您当地的数据保护机构投诉。

## 跨境传输

我们的子处理方可能在您所在国家/地区以外的国家（包括美国）处理数据。在必要情况下，此类传输受到适当的保障措施（例如标准合同条款）的保护。

## 儿童

本服务不面向儿童，也不适合任何未达到其当地法律规定的数据处理同意年龄的人使用。我们不会在知情的情况下收集儿童的个人数据。
