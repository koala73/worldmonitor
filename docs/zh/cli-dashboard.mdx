World Monitor 也可以在终端中以全屏仪表盘的形式运行。它与[命令行客户端](/zh/cli)一同包含在 [`worldmonitor`](https://www.npmjs.com/package/worldmonitor) npm 包中，无需 API 密钥，显示的实时数据与[网页仪表盘](https://www.worldmonitor.app/dashboard)相同：世界地图、新闻排名、市场、冲突与不稳定性、军机与航运、网络威胁、气候灾害、预测市场、直播电视与网络摄像头，以及平台健康状况。

## 启动

```sh
npx worldmonitor            # run once without installing
npm install -g worldmonitor # or install the `worldmonitor` command (alias `wm`)
worldmonitor                # open the dashboard (same as `worldmonitor tui`)
```

在交互式终端中不带参数运行 `worldmonitor` 会打开仪表盘。在管道、脚本或 CI 中则会打印帮助信息，因此现有的自动化不受影响。按 `q` 退出，终端会恢复原状。

### 运行要求

- **Node.js 18 或更高版本。** 该包没有任何依赖。
- **至少 80×24 的交互式终端。** 窗口越大，可并排显示的面板越多；160×45 或更大可获得本页所示的完整布局。
- **支持真彩色与鼠标的终端**效果最佳，例如 Ghostty、kitty、WezTerm、iTerm2、Konsole、Alacritty 或 VS Code 终端。不报告真彩色支持的终端（包括 macOS 自带的“终端”）使用 256 色。
- **包含盲文与制表符字符的字体**，用于绘制地图与面板边框。大多数现代终端字体都包含这些字符。
- **可选：** 安装 [mpv](https://mpv.io) 与 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 以在终端中播放直播电视与网络摄像头。未安装时，直播流会在浏览器中打开。

## 选项

| 参数 | 作用 |
|---|---|
| `--theme <id>` | 以指定主题启动：`neon`、`matrix`、`amber`、`redalert`、`ice`、`synthwave` |
| `--no-anim` | 关闭动画（雷达扫描、滚动条、打字机式简报）。运行时按 `a` 切换 |
| `--fps <n>` | 动画帧率，5–60（默认 20） |
| `--base-url <url>` | 自托管部署的 API 地址 |
| `--api-key <key>` | 使用你的 API 密钥代替匿名会话 |

这些参数仅对终端仪表盘生效。`worldmonitor web` 有自己的参数，见[打开网页仪表盘](#打开网页仪表盘)。在其他所有命令中，`--theme`、`--url` 等参数会作为请求参数传给 API。

| 环境变量 | 作用 |
|---|---|
| `WORLDMONITOR_API_KEY` | 代替匿名会话使用的 API 密钥 |
| `WORLDMONITOR_BASE_URL` | API 地址，与其他 CLI 命令共用 |
| `WORLDMONITOR_TUI_BASE_URL` | 仅用于仪表盘的 API 地址 |
| `WM_TUI_COLOR` | 颜色检测有误时强制使用 `truecolor` 或 `256` 色 |
| `WM_TUI_VO` | 强制指定 mpv 的终端视频输出，例如 `kitty` 或 `tct` |
| `WM_TUI_FORCE` | 即使 stdin 或 stdout 不是终端也启动仪表盘 |

## 数据与隐私

仪表盘读取与网页仪表盘相同的公开端点：公开 bootstrap 数据层、新闻摘要、精简健康检查端点与版本端点。军机与船舶快照使用匿名的短期会话令牌，其生成方式与浏览器相同。设置了 `WORLDMONITOR_API_KEY` 或 `--api-key` 时会改为发送该密钥。

数据在后台刷新：快速数据层每分钟一次，新闻与健康状况每 2 分钟一次，慢速数据层每 5 分钟一次。军机与船舶数据仅在 Air & Sea 视图打开时刷新。加载失败的数据源会等待一段时间后重试，System 视图会显示其错误。

## 打开网页仪表盘

```sh
worldmonitor web
```

在浏览器中打开 [worldmonitor.app/dashboard](https://www.worldmonitor.app/dashboard)。如果在 World Monitor 仓库的克隆目录中运行，则会启动本地开发服务器（`npm run dev`）并打开本地地址。

| 参数 | 作用 |
|---|---|
| `--hosted` | 即使在仓库目录中也始终打开托管版仪表盘 |
| `--port <n>` | 本地开发服务器端口（默认 5173） |
| `--no-open` | 只打印地址，不打开浏览器 |
| `--url <url>` | 打开此地址，而非托管版仪表盘。在仓库目录中需同时加上 `--hosted`，否则会启动本地开发服务器 |

## 故障排除

- **地图或边框显示为方框或问号。** 你的字体缺少盲文或制表符字符。请改用 JetBrains Mono、Fira Code、SF Mono、Menlo 或 Cascadia Code 等现代终端字体。
- **颜色发灰或不正确。** 你的终端可能没有报告真彩色支持。设置 `COLORTERM=truecolor`；如果终端只支持 256 色，则设置 `WM_TUI_COLOR=256`。
- **在 tmux 中鼠标无效。** 在 tmux 配置中加入 `set -g mouse on`。
- **提示 “The dashboard needs an interactive terminal”。** stdin 或 stdout 是管道或文件。请直接在终端中运行 `worldmonitor tui`，或使用[脚本命令](/zh/cli)进行自动化。
- **视频无法播放。** 查看 System 视图中的播放器部分。mpv 与 yt-dlp 必须位于 `PATH` 中，否则直播流会在浏览器中打开。
- **某个视图为空。** 打开 System 视图查看哪个数据源失败以及何时重试。按 `r` 刷新当前视图。
