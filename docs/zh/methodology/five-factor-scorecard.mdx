title: "五因素国家评分卡"
description: "食品、能源、人口结构、科技和国防能力的绝对 1–5 分评分，包含来源信息与集团汇总规则。"
---

五因素评分卡回答一个国家或集团的五个结构性问题：能否供应食品、供应能源、维持人口与劳动力、开发和使用科技，以及保卫自身。它是基于来源观测的年度判断层，不是国家不稳定指数（CII）或国家韧性指数（CRI），也不替代它们。

## 版本约定

- **方法版本：** `1.0.0`
- **输入注册表：** `1.0.0`
- **存储模式：** `1`
- **规范快照：** `scorecard:five-factor:v1`
- **原子读取模型：** `scorecard:five-factor:v1:read-model`
- **种子健康：** `seed-meta:scorecard:five-factor`

任何权重、目标点、档位、覆盖下限、必需组、汇总规则或输入映射的变化，都必须更新方法版本与变更日志。存储结构变化还必须更新模式版本。

## 通用评分规则

每个输入按冻结的目标点归一化为绝对 0–100 分，超出范围的值会被截断。评分器计算可用输入权重之和作为 `inputCoverage`，按可用权重重新归一化加权均值，检查覆盖下限与必需组，再把未四舍五入的连续子分数映射为整数档位。不可用输入不会得到中性分，也不会进入均值。

当证据不足时，支柱返回 `hasScore=false`，而内部值为 `score=null` 与 `subScore=null`。公共 proto3 响应会用零占位，所以客户端必须先检查 `hasScore`。

| 未四舍五入的子分数 | 档位 | 一般含义 |
|---:|---:|---|
| `0 <= x < 20` | 1 | 严重结构性缺口 |
| `20 <= x < 40` | 2 | 明显缺口与外部依赖 |
| `40 <= x < 60` | 3 | 能力混合，仍有重要缺口 |
| `60 <= x < 80` | 4 | 能力强，缺口可管理 |
| `80 <= x <= 100` | 5 | 高度自给或高能力 |

下限包含在较高档位内。例如，40.0 正好是档位 3。发布的连续子分数保留两位小数，覆盖率保留四位小数。档位始终由未取整的子分数推导，因此四舍五入不会改变档位；但在边界附近两者可能按设计不一致：连续子分数 `19.996` 会发布为 `subScore: 20.00` 而 `band: 1`，并非 `band: 2`。请直接读取发布的 `band`，不要用发布的 `subScore` 重新推导。

### 不可用原因

封闭原因集合为：`source-unavailable`、`country-unavailable`、`invalid-value`、`stale`、`coverage-below-floor`、`required-group-missing`、`missing-population` 与 `redistribution-blocked`。每条可用证据包含输入 ID、数值、年份、单位、来源和来源键。保留的最后成功观测使用 `quality=retained`。

### 新鲜度与发布下限

V1 在评分前检查观测年龄。人口、食品平衡、食品库存和年龄结构最多 3 年；一次能源平衡最多 4 年；低碳发电、贸易多样性、劳动力和国防最多 5 年；其他年度输入最多 7 年。边界年份仍可用。来源内容年龄约定过期时，即使 Redis 仍保存数值，证据也返回 `stale`。

新的每日批次只有在至少 180 个国家有一个可评分支柱、至少 150 个国家有可用人口证据，并达到食品 80、能源 120、人口结构 150、科技 120、国防 30 的可评分国家下限时，才替换最后成功批次。健康端点分别报告人口与五个支柱的计数。部分来源故障不会刷新健康状态或覆盖更完整的批次。

## 五个支柱

### 食品

来源以千公吨为单位，按 `千公吨 * kcal/kg / 1,000,000` 转换为万亿千卡后再汇总。

| 组成 | 权重 | 方向与目标点 |
|---|---:|---|
| 热量生产 / 消费 | 0.55 | 越高越好；`0.50 -> 0`，`1.25 -> 100` |
| 热量期末库存 / 总使用 | 0.25 | 越高越好；`0.05 -> 0`，`0.25 -> 100` |
| 水安全 | 0.15 | 压力越低越好；`100 -> 0`，`10 -> 100` |
| 进口伙伴多样性代理 | 0.05 | HHI 越低越好；`0.65 -> 0`，`0.15 -> 100` |

覆盖下限为 **0.70**，生产 / 消费是必需输入。来源包括 USDA PSD、FAOSTAT、世界银行 AQUASTAT 静态证据与 UN Comtrade。集团先汇总生产与消费，再计算比率；库存与总使用也先汇总。水安全和进口多样性按有证据成员的人口加权。

### 能源

消费来自 OWID `primary_energy_consumption`。生产根据世界银行净能源进口 `EG.IMP.CONS.ZS` 推导：

```text
生产 TWh = 消费 TWh * (1 - 净进口百分比 / 100)
```

| 组成 | 权重 | 方向与目标点 |
|---|---:|---|
| 一次能源生产 / 消费 | 0.60 | 越高越好；`0.25 -> 0`，`1.25 -> 100` |
| 低碳发电占比 | 0.25 | 越高越好；`0% -> 0`，`80% -> 100` |
| 电网输送效率 | 0.15 | 损耗越低越好；`25% -> 0`，`3% -> 100` |

覆盖下限为 **0.60**，生产 / 消费是必需输入。集团先汇总生产与消费 TWh，再评分；其他组成按人口加权。

### 人口结构

| 组成 | 权重 | 方向与目标点 |
|---|---:|---|
| 总抚养比 | 0.15 | 越低越好；`100 -> 0`，`35 -> 100` |
| 老年抚养比 | 0.10 | 越低越好；`50 -> 0`，`10 -> 100` |
| 10 年工作年龄人口比 | 0.20 | 越高越好；`0.80 -> 0`，`1.10 -> 100` |
| 高等教育入学率 | 0.15 | 越高越好；`20% -> 0`，`90% -> 100` |
| 每百万人研究人员 | 0.10 | 越高越好；`100 -> 0`，`5,000 -> 100` |
| STEM 毕业生占比 | 0.10 | 越高越好；`10% -> 0`，`40% -> 100` |
| 受训工业职业占比 | 0.15 | 越高越好；`2% -> 0`，`25% -> 100` |
| 制造业就业占比 | 0.05 | 越高越好；`5% -> 0`，`25% -> 100` |

覆盖下限为 **0.60**。必须至少有一个年龄结构输入，以及一个教育、研究或劳动力输入。集团按人口加权成员未四舍五入的连续子分数，绝不平均整数档位。

### 科技

| 组成 | 权重 | 方向与目标点 |
|---|---:|---|
| 互联网使用率 | 0.20 | `20% -> 0`，`95% -> 100` |
| 移动订阅 | 0.10 | 每百人 `50 -> 0`，`150 -> 100` |
| 固定宽带 | 0.15 | 每百人 `0 -> 0`，`45 -> 100` |
| 研发支出 | 0.25 | `0.2% -> 0`，`4% -> 100` |
| 每百万人研究人员 | 0.15 | `100 -> 0`，`5,000 -> 100` |
| STEM 毕业生占比 | 0.10 | `10% -> 0`，`40% -> 100` |
| 电力接入率 | 0.05 | `50% -> 0`，`100% -> 100` |

覆盖下限为 **0.65**，必须至少有一个连接性输入和一个创新输入。世界银行原始观测、年份与指标代码保留在证据中。集团按人口加权连续子分数。

### 国防

| 组成 | 权重 | 方向与目标点 |
|---|---:|---|
| 军费（美元） | 0.20 | 对数尺度；`$100m -> 0`，`$100bn -> 100` |
| 军费占 GDP | 0.15 | `0.5% -> 0`，`5% -> 100` |
| 武装部队人员 | 0.15 | 对数尺度；`10,000 -> 0`，`1,000,000 -> 100` |
| 武器出口占转移总量 | 0.30 | `0 -> 0`，`1 -> 100`；同年出口 /（出口 + 进口） |
| 供应商多样性 | 0.20 | HHI 越低越好；`0.65 -> 0`，`0.15 -> 100` |

覆盖下限为 **0.50**。必须有一个态势输入（支出或人员）和工业平衡输入。SIPRI 原始转移记录不会存储或返回；在来源政策允许公开使用已推导 HHI 前，供应商多样性明确返回 `redistribution-blocked`。集团按人口加权连续子分数。

只有出口和进口都是同年、明确且有限的观测值时，工业平衡才可用。缺失的一方不会转换为零；明确观测到的零仍然有效。

## 集团规则

V1 官方预设为 `USMCA`、`EU27`、`BRICS`、`GCC`、`ASEAN` 与 `NATO`。自定义集团接受 2–30 个唯一的大写 ISO-2 代码。一次请求必须选择一个预设或一个自定义列表。

成员资格于 2026-08-29 根据[欧盟国家名单](https://european-union.europa.eu/principles-countries-history/eu-countries_en)、[BRICS 成员名单](https://brics.br/en/about-the-brics)、[东盟成员名单](https://asean.org/member-states/)和[北约成员历史](https://www.nato.int/cps/en/natohq/nato_countries.htm)核对。东盟预设包括东帝汶，BRICS 使用官方 11 国名单。成员变化必须记录在方法变更日志中。
