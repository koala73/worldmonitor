## 目的

[国家韧性指数](/zh/methodology/country-resilience-index)为每个国家发布一个评分。本路由发布其背后的算术：全部 72 项注册指标、每一项的贡献值，以及每个数字的来源。

它的存在是为了让评分可被审计。如果某国的韧性发生变动，这就是说明哪项指标变动、变动多少的端点。

由 `GET /api/resilience/v1/get-resilience-indicators?country_code=<ISO2>` 与 MCP `get_resilience_indicators` 提供。两者均需 Pro 订阅。此路由没有仪表盘界面——它是面向 API 与智能体的端点。

## 每项指标

72 行中的每一行携带：

| 字段 | 含义 |
| --- | --- |
| 归一化得分 | 该指标在引擎通用标度上的取值 |
| 状态 | 该值是**观测**得来还是**插补**得来 |
| 运行时权重 | 本次运行实际应用的权重，而非注册表默认值 |
| 贡献值 | 该指标在其维度中的占比，经对账后维度内贡献值可正确求和 |
| 观测时效 | 底层观测值的年龄 |
| 来源出处 | 由哪个上游发布 |

权重按实际应用值提供而非按配置值，因为当某指标对某国不可用时引擎会重新归一化。读取注册表默认值会错误归因该评分。

## 观测与插补

插补指标是评分的真实组成部分，并未被隐藏——但它是建模值而非测量值。任何将二者等同看待的审计都会高估覆盖稀薄国家的得分。`state` 字段正是区分二者的依据。

## 原始数值与许可

原始来源数值**仅在上游许可允许再分发时**包含在内。其他情况下提供归一化得分与出处，但不含底层数字。

该缺失是许可边界，而非数据缺失——引擎拥有该数值并已使用它；WorldMonitor 不得再次发布它。各来源的条款记录于[韧性指标许可](/zh/methodology/resilience-indicator-licensing)。

## 对账

贡献值按维度对账后报告，而非以原始乘积形式呈现。调用方可以在一个维度内累加贡献值得到该维度的得分；跨维度按维度权重求和则得到国家得分。未能对账的数值不会被悄悄四舍五入凑合——该指标转而报告其状态。
