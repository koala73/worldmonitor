Pro 指标下钻会返回全部 72 行已注册指标，并在评分器具备归一化分数时一并返回该分数。只有在以下条件全部成立时才会返回原始来源值：该观测值是实测得到的、每个参与贡献的提供方都已完成再分发审查、响应中包含所需署名，且确切的贡献种子具有抓取时间戳。插补、回退、缺失、未启用、已退役、不适用、来源失败、提供方不明确或抓取时间不明确的行，永远不会包含原始值。

指标注册表中宽泛的 `license` 标签属于来源清单元数据，并不构成再分发许可。`server/worldmonitor/resilience/v1/_indicator-source-policy.ts` 中的可执行策略更为严格，并依据每个观测值的确切提供方溯源作出判断。

REST 与 MCP 的发现接口不为该响应公布 JMESPath 投影能力。两个运行时都会拒绝非空投影请求，因为投影可能使被允许的原始值脱离授权其再分发的署名与抓取字段。

每个来源条目都包含数据集 URL、许可标签、规范 `licenseUrl`，以及在所需署名目标与数据集 URL 不同时的独立 `attributionUrl`。

## 时间与溯源字段

`sourceYear` 或来源观测时间戳描述提供方**测量**该现象的时间；`retrievedAt` 描述 WorldMonitor **抓取或播种**它的时间。两者不可互换。来自静态韧性批次的 World Bank 观测值使用所选国家载荷的 `seededAt`。从较早批次恢复的数据集使用其自身的 `_recovered.seededAt`，而不是新批次的元数据时间。其他来源路径在其确切贡献种子的抓取时间戳被带入追踪之前仍不可用。当该时间戳不可用时，即使原始值本可授权，API 也会将其扣留；它不会复用响应数据版本或另一个种子的时间。观测年龄始终依据来源观测日期计算，而非抓取时间。如果来源未发布观测日期，API 会将来源年份与观测年龄留空。

当一个复合指标使用了不同年份的观测值时，`sourceYear` 取贡献年份中最早的一个。这一保守规则可防止较新的组成部分掩盖较旧输入的年龄。

复合指标必须列出对选定值有贡献的每一个提供方。上述 World Bank/Eurostat 与 World Bank/UN Comtrade 的有条件决策都依赖这一点。

## 抑制原始值时的归一化分数

归一化分数是 WorldMonitor 在方向、标杆值、运行时加权及任何有记录的策略调整之后得出的派生输出。因此，即便上游条款阻止原始值再分发，API 仍可公开归一化分数与有效贡献。抑制通过原始值策略状态与原因来表示，而不是用数值零表示。

## 失败关闭的审查规则

1. 对未知指标或缺失提供方溯源的情形，默认不提供原始值。
2. 要求 `observed` 状态。绝不为插补、回退、缺失或未启用的行公开原始数据。
3. 检查复合观测值中的每一个提供方。任何一个未经审查的组成部分都会抑制整个原始值。
4. 不得仅凭注册表许可类别、来源键、提供方的公开可访问性或署名声明来推断许可。
5. 每条允许决策都须保留提供方署名、来源链接、许可标签与许可 URL。`observationProvenance` 字段用于区分确切的选定来源与仅来自注册表的署名。
6. 当来源、镜像、提取路径或数据集专属条款发生变化时，须重新审查提供方条款。
7. 在为新的注册表条目提供服务之前，先把该指标加入穷举式策略表及其测试。

生产环境的响应读取由六小时公共分数缓存引用的不可变追踪代次。该大体积追踪存放在独立的七小时边车中，因此分数与排名读取保持轻量。边车缺失或损坏会重建并重新发布完整的分数代次；处理程序绝不会在较旧的缓存分数旁重新扫描当前种子。确认的来源键未命中可产生有记录的缺失或插补状态。Redis 读取错误会使代次构建失败，且不会作为有效响应被缓存。
