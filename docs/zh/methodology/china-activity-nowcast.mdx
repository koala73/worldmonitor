description: "以确定性方法比较可追踪修订版本的官方经济活动数据与经过审核的物流、运营、商品和市场代理指标。"
---

中国经济活动即时预测是一项透明的方向性比较。它不是 GDP 替代估算，
也不是对隐性经济活动的验证，更不是中国风险评分。数值计算、输入资格、
方向、置信度和状态判定均不使用语言模型。

当前方法版本为 `china-activity-nowcast/v1`。

## 官方对比序列

第一版方法使用可追踪修订版本的中国宏观数据契约，并在每个评估时点选择
最新且符合条件的官方经济活动观测。观测必须同时满足以下条件：

- 观测期在发布时间之前结束；
- 发布时间早于获取时间；
- 获取时间不晚于评估时间；
- 该数据版本具有有效的来源溯源信息；
- 观测可用且未过期；以及
- 已发布的方向性比较为走强、走弱或持平。

API 和面板会保留所选序列、观测期、发布时间、获取时间和版本 ID。
历史评估只能选择在该评估时点之前已获取的数据版本，后续修订不能替换
较早时点实际可见的数值。

## 经审核的代理指标注册表

每个指标族均在 `shared/china-activity-nowcast-registry.ts` 中声明经过审核的
选择理由、单位、转换方法、频率、滞后规则、新鲜度预算、对齐规则和来源。

| 指标族 | 第一版观测 | 转换方法 | 频率 | 滞后 | 新鲜度预算 |
| --- | --- | --- | --- | --- | --- |
| 货运 | 中国出口集装箱运价指数变化 | 仅使用已发布的带符号百分比变化 | 每周 | 无 | 28 天 |
| 海运 | 经审核的 PortWatch 趋势差值 | 对配置节点的有限趋势差值取平均 | 每日 | 无 | 72 小时 |
| 航空 | 经审核的枢纽正常/中断平衡 | 正常占比减去中断占比 | 日内 | 无 | 180 分钟 |
| 能源 | 已发布的中国能源需求变化 | 仅使用已发布的带符号百分比变化 | 每月 | 30 天 | 210 天 |
| 商品 | 铜和铝的价格变化 | 对已发布的有限百分比变化取平均 | 每日 | 无 | 180 分钟 |
| 走廊 | 可比走廊活动广度变化 | 当前指标族数量减去此前可比快照 | 每日 | 无 | 72 小时 |
| 市场 | 上证综指周度变化 | 使用已发布的带符号百分比变化 | 每日 | 无 | 10 天 |

注册表不会把“来源存在”解释为“经济活动”。例如，能源数据载荷仅表明
JODI 数据可用，并不能证明需求方向；同样，只有当前 CCFI 水平而没有
可比的前值，也不能构成运价变化。在所消费的数据契约发布所需的方向性
观测之前，这些输入会保持明确排除状态。

## 对齐与缺失值

默认比较窗口为 90 天。方法先等待每个注册项规定的滞后期结束，再选择
比较窗口内最新的实际观测。

所有指标族均禁止前向填充和插值。当最新观测过期、结构上不可比较、
不可用、缺少溯源信息、位于窗口之外或缺少必要前值时，方法不会回退到
更早的观测。每个此类输入都会显示排除原因，且不会被转换为中性方向。

## 方向性状态

方法至少需要三个符合条件且非持平的代理指标族，以及一个方向非持平的
官方数据版本。只有当至少三分之二的合格代理指标指向同一方向时，才会
形成代理指标共识。

方法只会输出以下五种状态之一：

- `agreement`：代理指标共识与官方方向一致；
- `proxy_leading_divergence`：代理指标共识与官方方向不同，且代理指标的
  对齐观测中位时间晚于官方观测期；
- `official_leading_divergence`：代理指标共识与官方方向不同，但代理指标
  并未领先官方观测期；
- `mixed_signals`：已有足够的指标族，但未形成三分之二共识；或
- `insufficient_data`：官方数据或代理指标族覆盖率低于方法要求。

每个纳入计算的贡献项都会保留转换后的数值、方向、时间、来源和完整的
注册表元数据。响应不会输出汇总经济活动评分。

## 置信度与敏感性

置信度为分类值：`high`、`medium`、`low` 或 `insufficient`，并会报告
符合条件的指标族覆盖率。方法还会逐一移除每个代理指标族并重新计算状态。
面板会显示这种留一指标族检验是否改变结论，使单一指标族的支配影响可被
检查。

## 历史评估

`backtestChinaActivityNowcast()` 使用同一套时点资格路径，对一组明确的
历史时间进行评估，并报告：

- 尝试评估和可评估的记录数；
- 覆盖率；
- 可评估记录中的方向一致率；
- 每条记录使用的官方数据版本；以及
- 每条记录的比较状态和合格指标族数量。

官方修订和代理指标的发布、获取时间均执行防止前视偏差的过滤。当前实时
缓存仅包含当前快照，不包含有界的历史代理指标账本。因此，公开响应会
明确说明历史评估不可用，而不会用当前值伪造回测。只有在这类历史账本
得到保留和审核后，才会发布历史覆盖率。

## 缓存与 API 行为

`GET /api/economic/v1/get-china-activity-nowcast` 返回一个小型包装对象和
经过规范验证的 JSON 载荷。健康结果使用 15 分钟服务器缓存。
`insufficient_data` 结果不会被正向缓存，浏览器断路器也不会保留可能
掩盖当前中断或输入缺失的旧成功副本。只有在官方数据版本和代理指标贡献
均不存在时，包装对象的 `upstream_unavailable` 才为 true；其他健康但
缺少方向的信息属于方法证据不足，而不是上游故障。

端点组合以下数据：

- 官方中国宏观快照；
- 中国物流走廊控制塔响应；
- 规范商品种子数据及其种子健康时间戳；以及
- 由 Railway 服务维护的中国股票指数快照。

各依赖项的故障彼此隔离。方法可以保留未受影响的指标族，但所有依赖均
丢失时会返回 `insufficient_data`，并将全部贡献标记为排除。方法版本发生
变化时，必须使用新的版本字符串和新的可复现测试夹具，不能静默改变历史
语义。
