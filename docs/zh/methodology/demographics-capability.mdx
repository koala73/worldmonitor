## 从这里开始

这里回答的是一个听上去简单、实际上并不简单的问题：**这个国家有没有能干活的人？**

"能干活的人"可以拆成三件互不相同的事，而一个国家完全可能在其中一项上很强、在另一项上是空的：

1. **足够多的劳动年龄人口**——现在有，十年之后仍然有。
2. **一条能产出技能的管道**——高校、STEM 毕业生、研究人员。
3. **一支真能造东西的劳动力**——受过训练的工业技工、机械操作工、制造业就业。

一个人口年轻但没有工程师的国家，和一个拥有世界级大学、劳动力却退休得比补充还快的国家，完全不是一回事。这两者在单一混合数字里都会显得"中等"——这正是本数据不以单一指数发布的原因。

<Warning>
**不要把这三个组别平均在一起。** 它们来自不同的数据源，遵循不同的时钟。某国工业劳动力数据是八年前的、年龄结构是最新的，并不意味着它有一份八年前的人口画像；它有的是两项必须分开阅读的观测值。响应刻意让它们保持分离。
</Warning>

<Info>
**访问方式。** 由 `GET /api/resilience/v1/get-demographics-capability?countryCode=<ISO2>` 与 MCP `get_demographics_capability` 提供。两者均需 Pro 订阅。
</Info>

## 三个独立组别

响应刻意不是单一的混合指数。每个组别各自解析，来自各自的数据源，遵循各自的时钟。

### 年龄结构——联合国世界人口展望

`medianAgeYears`、`workingAgePopulationPeople`、`oldAgeDependencyRatioPercent`、`totalDependencyRatioPercent`，以及前瞻性的 `workingAgePopulationProjected10yPeople`。WPP 每两年发布一次修订；两次修订之间的预测值来自同一序列，而非新的估算。

### 教育管道——UNESCO UIS 与世界银行 WDI

`tertiaryEnrollmentGrossPercent`、`stemGraduatesSharePercent` 与 `researchersPerMillion`。UIS 为主；WDI 在 UIS 覆盖中断处补充。报告滞后很长——三到五年属于常态，而非缺陷。

### 工业劳动力——ILOSTAT

`manufacturingEmploymentSharePercent`、`trainedIndustrialWorkforcePeople`、`craftTradesEmploymentPeople` 与 `plantMachineOperatorsEmploymentPeople`。ILOSTAT 的覆盖是三者中最稀薄的：一个国家可能拥有最新的 WPP 年龄结构，却完全没有可用的 ILOSTAT 观测值。

## 阅读响应

每项指标携带四样东西：数值、其 `year`、其 `source`、其 `unit`，以及明确的 `available` 标志。

**先读 `available`，再读数值。** 这些是 proto3 消息——缺失的数字会序列化为 `0`，而中位年龄为零或制造业占比为零绝不是真实观测值。该标志是区分"已测量"与"缺失"的唯一依据。

**不要跨组别取平均。** 它们的年份与覆盖不同。一个国家的 ILOSTAT 记录有八年之久而 WPP 记录是最新的，并不意味着它拥有八年前的人口概况；而是意味着有两个必须分开阅读的观测值。响应将它们分开正是出于此因。

**滞留状态在 `stages[].status` 上，而不在每个数值上。** 阶段状态为 `fresh`、`retained` 或 `unavailable`。`retained` 表示该源组别因当前上游请求失败而从此前抓取中沿用。单个观测值没有 `retained` 字段。

顶层的 `available: false` 表示没有任何组别解析成功——该国在三者中均无可用观测值，这不同于各组别各自携带部分可用性的国家。

## 更新频率

种子程序按该数据集最慢的有用周期刷新。上游发布是约束条件：WPP 每两年一次，UIS 与 WDI 每年一次但有多年滞后，ILOSTAT 按国家不定期发布。
