`prepare_travel_risk_assessment` MCP 工具为一次行程起草出行风险评估。你按出行顺序提供国家，并可选地提供城市和日期。工具以 Markdown 和结构化区块两种形式返回草稿。每条发现都注明来源以及该来源给出的日期；无法读取的来源会标为不可用，并说明原因。

这份草稿是分析师工作的起点。它报告 World Monitor 数据中关于每个国家的内容，为没有数据覆盖的主题留出空白标题，并且不给出任何自身建议。

这是第一阶段，仅通过 MCP 提供。从 World Monitor 应用内导出草稿计划在后续阶段推出。

## 所需套餐

该工具包含在 **Pro Business**、**API Business** 和 **Enterprise** 套餐中。Enterprise 账户的成员同样可以使用。

Pro、API Starter 和免费账户可以在 `tools/list` 中看到该工具，但调用会返回 JSON-RPC 错误 `-32002`（HTTP 403），并带有 `data.reason: "upgrade-required"` 和 `data.planFeature: "travelRiskAssessment"`。无论客户端通过 OAuth 登录还是发送 API 密钥，服务器都会对每个调用方检查套餐。拒绝发生在读取参数之前，也发生在计入任何额度之前，因此被拒绝的调用不产生费用。完整的拒绝结构及其指向的升级路径，请参阅 [MCP 错误目录](/zh/mcp-error-catalog)。

在拥有独立 MCP 额度的套餐（例如 Pro Business）中，每次调用计 1 次。在 MCP 与 HTTP API 共用同一额度的套餐（例如 API Business）中，每次调用计 2 次，与其他多来源工具相同。

## 输入参数

| 参数 | 必填 | 形式 | 说明 |
|---|---|---|---|
| `countries` | 是 | 1 到 6 个对象组成的数组，按出行顺序排列 | 每个国家只能出现一次。 |
| `countries[].country_code` | 是 | ISO 3166-1 alpha-2 代码，例如 `TH` | 不接受 alpha-3 代码和国家名称。 |
| `countries[].cities` | 否 | 最多 5 个城市名称 | 用于标记位于所列城市的动荡信号和机场，不会缩小数据返回的范围。 |
| `countries[].arrive`、`countries[].depart` | 否 | `YYYY-MM-DD` | `depart` 必须不早于 `arrive`；如果给出行程窗口，两者都必须落在窗口内。 |
| `date_from`、`date_to` | 否 | `YYYY-MM-DD` | 行程窗口。`date_to` 必须不早于 `date_from`。 |
| `task_label` | 否 | 最多 120 个字符 | 打印在草稿顶部，例如项目或行程编号。 |
| `jmespath` | 否 | JMESPath 表达式 | 在服务端对结果进行投影。参见 [JMESPath 指南](/zh/mcp-jmespath)。 |

工具会拒绝任何未列出的参数。它没有用于旅客姓名、护照号码、联系方式或地址的字段，也不应在 `task_label` 或 `cities` 中发送这些信息。

完整的参数参考及请求示例见 [国家工具参考](/zh/mcp-tools/countries#prepare_travel_risk_assessment)。智能体可以按照 [prepare-travel-risk-assessment 技能](https://www.worldmonitor.app/.well-known/agent-skills/prepare-travel-risk-assessment/SKILL.md) 操作。

## 草稿结构

Markdown 草稿共有 9 个编号部分。第 2 到第 7 部分按出行顺序为每个国家各列一组区块。

1. **摘要。** 总体评级，即行程中最严格的国家评级；随后是每个国家的评级和一段简短说明。国家评级取美国国务院与澳大利亚 Smartraveller 两者中较高的级别，两者采用相同的 1 到 4 级标准。英国 FCDO 和 CDC 的级别列在旁边，不换算到该标准。
2. **政府出行建议。** 该国当前的美国国务院、英国 FCDO、澳大利亚 Smartraveller 和 CDC 条目，以及美国使馆警报，每条都附发布日期。
3. **安全。** 过去 30 天的 UCDP 武装冲突事件、来自媒体报道的动荡信号（未经核实）、World Monitor 精选热点，以及国家不稳定指数（仅限其评分覆盖的国家）。
4. **自然灾害。** 天气警报、地震，以及自然事件和热带气旋。季节性灾害始终标为不可用，因为 World Monitor 没有气候学数据。
5. **健康。** 疾病暴发报告和 CDC 旅行健康通告。
6. **出入境交通。** World Monitor 在该国监测的机场状态；服务于所列城市的机场会被标记。
7. **通信与基础设施。** Cloudflare Radar 报告的互联网中断。
8. **本草稿未覆盖的内容。** 街头犯罪、医疗设施、当地法律与习俗、紧急联系方式以及特定场所风险的空白标题，由分析师补充。
9. **来源与采集时间。** 草稿读取的每个来源、其生产方最近一次更新的时间，以及调用时该来源是最新、过期还是不可用。

每个区块都带有状态。请先读状态，再读发现。

| 状态 | 含义 |
|---|---|
| `reported` | 来源中有该国的条目。每条发现都有 `source` 和 `observed` 日期；来源未给出日期时为 `null`。 |
| `none` | 已读取来源，但在说明所述的时间窗口内没有该国的内容。 |
| `unavailable` | 无法读取来源，因此情况未知。这并不代表没有风险。 |
| `not_covered` | 没有来源覆盖该国的这一主题。 |

某个来源失败时，只有依赖它的区块会被标为不可用，草稿的其余部分照常返回。只有在所有来源都无法读取时，调用才会以 `-32003` 失败。

## 数据处理

行程计划属于敏感信息，因此工具只将你发送的内容用于生成响应。

- 国家、城市、日期和任务标签不会写入日志、使用遥测、错误报告或缓存键。使用记录只包含工具名称和结果，从不包含参数。
- 服务器不保留请求或草稿的副本。草稿基于共享的国家级数据生成，服务器对每个调用方都以相同方式读取这些数据。
- 当参数无效时，错误会指出字段及其违反的规则，但不会回显你发送的值。

草稿会复述你的行程。请像对待行程计划本身一样存储和分享它。
