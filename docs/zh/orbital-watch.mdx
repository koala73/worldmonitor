## 概览

轨道观察回答一个问题：对地球上任意一点，哪些卫星经过了它，其中是否有卫星留下了公开影像？在地图上右键（触屏设备长按），选择 **经过此处的卫星**。面板会列出过去 7 天和未来 72 小时内的每一次过境，并按证据所能支持的程度分组。

过境不等于影像。头顶经过的大多数卫星没有对准该点的相机，有相机的也常常没有被分配拍摄该点，有些影像从未公开。只有公开存档返回影像时，轨道观察才会显示影像。

## 方法

### 由轨道根数计算过境

[CelesTrak](https://celestrak.org) 目录提供每颗卫星的通用摄动轨道根数。浏览器在后台线程中用 SGP4 模型（satellite.js）进行传播，找出卫星覆盖范围经过该点的时刻。一颗卫星有多组根数时，每组只负责时间窗口中离其历元最近的部分，因为一组根数跨越多天传播会产生漂移。

### 传感器配置

每颗卫星对应一个传感器配置，说明它能看到什么、之后可以期待什么：

| 字段 | 含义 |
|---|---|
| 类别 | 开放光学（Sentinel-2、Landsat）、开放雷达（Sentinel-1）、极轨气象、商业光学、商业雷达、军事、载人空间站或地球静止 |
| 覆盖范围 | 仪器覆盖的地面条带，由幅宽或观测角、入射角计算 |
| 覆盖区域 | 任务是覆盖全球还是只覆盖陆地和海岸 |
| 存档等待 | 开放存档通常发布影像所需时间：Sentinel-2 和 Sentinel-1 为 24 小时，Landsat 为 72 小时 |
| 每日拼图 | 该传感器是否有每日全球拼图 |

光学传感器需要日照。只有当该点太阳高度角至少 5 度时，光学过境才会进入成像等级。夜间的过境仍会列出，等级为 `passed-overhead`。

### 与存档匹配

浏览器直接查询公开存档：Earth Search 和 Microsoft Planetary Computer 提供 Sentinel-2、Sentinel-1 和 Landsat 影像，NASA GIBS 提供每日拼图和地球静止卫星画面，EUMETSAT 提供 Meteosat 画面。影像的采集时间与计算出的过境时间相差不超过 5 分钟时，才归属于该次过境。对于光学影像，轨道观察还会读取该点本身的云分类，而不只是整景云量百分比。

## 结果等级

每次过境只有一个等级。等级只表达证据所支持的内容。

| 等级 | 含义 |
|---|---|
| `confirmed-image` | 开放任务经过，该点在覆盖范围内，光学传感器处于日照中，地面属于任务覆盖区域，且存档中有采集时间与过境相差 5 分钟以内的影像。显示该影像。 |
| `likely-imaged` | 条件相同，但存档尚未回应或存档等待期尚未结束。很可能有影像，但不显示。 |
| `passed-overhead`（**不在存档中**） | 条件相同，存档等待期已过，存档中没有匹配影像。该任务经过了上空，但没有发布该点的影像。 |
| `passed-overhead` | 其他所有过境：载人空间站、夜间的光学过境，或经过任务不覆盖的地面。不意味着有影像。 |
| `daily-mosaic` | 极轨气象卫星覆盖了该点，NASA GIBS 有当天的每日全球拼图时会显示。 |
| `within-reach` | 商业卫星经过，该点在其可拍摄范围内。商业影像需要付费下单拍摄，因此无法说明是否拍摄过。 |
| `capability-overhead` | 军事卫星经过，该点在其覆盖范围内。轨道观察只显示该能力经过了上空。 |
| `opportunity` | 未来的过境。这是拍摄机会，绝不是影像。 |

经过上空或在可拍摄范围内，绝不意味着拍摄了影像。只有 `confirmed-image`、每日拼图和地球静止卫星条目会显示影像，而且只显示公开存档返回的影像。

## 精度限制

- **轨道根数时效。** SGP4 误差随过境时间与所用根数历元之间的间隔增大。每次过境都会显示其轨道数据的时效。超过 7 天的根数不会使用，因此最新根数过旧的卫星不会给出过境，而不是猜测。
- **幅宽边缘不确定性。** 距覆盖范围边缘 5 公里以内的点标记为 **幅宽边缘**。微小的时间或姿态差异都可能使它落在影像内或影像外。
- **云。** 光学影像存在，也可能只拍到云。每张影像都会说明该点本身是晴空、有云还是在云影中，或者只知道整景云量。
- **存档延迟。** 开放存档在采集后数小时到数天才发布影像。任务的存档等待期结束前，没有影像的过境保持 `likely-imaged`，而不是 `passed-overhead`（不在存档中）。

## 变化标记

变化标记仍在规划中，目前尚未计算。变化标记将把某点的新影像与早前影像比较。它将首先以影子模式运行：标记会被计算并存储以供审核，但任何面板、风险评分、警报、API 端点或 MCP 工具都不会显示。至少影子运行 30 天、且至少 30 个已提出的标记经审核确认或撤回后，才会公开。

## 隐私

你选择的点保留在浏览器中，只会发送给浏览器直接调用的公开存档。分享链接中的坐标四舍五入到小数点后两位，约 1 公里。错误报告和其他遥测数据在离开浏览器之前，会从每个 URL 中删除坐标查询参数和坐标路径段。
