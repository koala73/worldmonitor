## 1. 本协议是什么

本最终用户许可协议（"本协议"）是管辖**你使用 World Monitor 的每一种方式**的许可协议。协议双方为你本人（如果你代表组织使用 World Monitor，则包括该组织）与位于阿拉伯联合酋长国的 World Monitor（"我们"）。

无论你通过哪个入口使用，本协议均适用：

- `worldmonitor.app` 上的**网页仪表盘**及其变体子域（tech、finance、commodity、energy、happy）；
- macOS、Windows 和 Linux 的**桌面应用**；
- **REST API** 与 **MCP 服务器**；
- **SDK 与命令行工具**（npm、Python、Ruby、Go）；
- **嵌入组件与小部件**，包括实时地图嵌入；
- **告警、Webhook、摘要与邮件**；
- 由上述任一入口产生的**导出、下载、报告与简报**。

我们把上述全部合称为"服务"，把服务产生的一切 —— 仪表盘视图、告警、报告、导出、API 与 MCP 响应，以及你在其基础上构建的分析 —— 合称为"输出内容"。

**接受方式。** 当你创建账户、订阅套餐、安装或启动桌面应用，或向 API 或 MCP 服务器发送请求时，即表示接受本协议。如果你代表某个组织接受本协议，即确认你有权约束该组织。如果你不同意，请勿使用本服务。

## 3. 定义

- **被许可用户** —— 你的套餐授权的一位具名个人。席位不是岗位、不是轮班、也不是共享登录。
- **你的组织** —— 就组织套餐而言，指订阅的那一个法律实体，包括为其工作的员工与承包商。
- **凭证** —— 账户登录信息、会话、API 密钥、许可密钥、MCP 令牌与 OAuth 授权。
- **派生事实** —— 我们计算得出的数值：韧性与风险评分、预测概率、指数、事件计数、聚合值与排名。
- **结构化事件** —— 标准化的事件记录：何事、何地、何时、类型、严重程度、实体，以及指向来源的链接，**不含**来源自身的文本。
- **来源内容** —— 第三方来源创作的文本、图像及其他表达：标题、正文、订阅条目与引文。
- **有效期** —— 你持有有效套餐或有效订单表的期间。

## 5. 你可以如何使用输出内容

输出内容并非只有一种，也不适用同一套权利。你可以保留、缓存和传递什么，取决于**该输出属于哪一类**，再取决于你的套餐。

| 类别 | 内容 | 你可以 | 留存期 | 可用性 |
| --- | --- | --- | --- | --- |
| **R1 —— 派生事实与评分** | 韧性与风险指数、预测概率、事件计数、聚合值、排名 | 在套餐范围内再分发，**可白标、无需署名** | **不限期** | 现已可用，覆盖所有来源 |
| **R2 —— 结构化事件** | 标准化的何事／何地／何时／类型／严重程度、实体与来源链接 —— **不含来源文本** | 在套餐范围内再分发，可在你自有或合作方界面中展示 | **不限期** | 现已可用，覆盖所有来源 |
| **R3 —— 标题与摘录** | 来源的标题、发布方名称、URL，以及不超过 200 个字符的文本 | 展示与缓存；来源署名必须保留，且**不可**白标 | **30 天** | 按来源、依申请开放 |
| **R4 —— 完整来源内容** | 第三方的原文、图像或媒体 | **仅限内部使用** | 套餐有效期内 | 永不可再分发 |

**默认规则。** 对于我们尚未逐一核验其提供方条款的来源，其**来源内容按 R4 处理**，而**由其派生的事实按 R1 与 R2 处理**。事实不属于任何人；通讯社写下的那句话则属于它。我们自由地许可前者，完全不许可后者。

**留存与缓存是明确授予的权利，而非默许。** 在上述类别范围内，你可以无限期存储、缓存、索引并重新查询 R1 与 R2 输出内容，包括在订阅结束之后，用于记录、审计与回溯检验。有效期结束后你不可再做的，是**抓取、刷新或运行**任何需要有效授权状态的集成（见第 10 节）。

**署名随输出内容一同传递。** 当输出内容附带来源引用、时间戳、许可声明或使用限制时，该声明必须在你制作的每一份副本、展示它的每一个界面上继续存在。

R3 权利按来源依申请开放 —— 请与我们联系，我们会告知哪些来源已获许可。

### 6.2 桌面应用

桌面应用由 World Monitor 的 AGPL-3.0-only 源代码构建。**应用程序二进制文件依据 AGPL-3.0-only 授权给你，而非依据本协议** —— 你可以按 AGPL 的条款运行、研究、修改和再分发它，本协议不会改变这一点。

本协议管辖的是**该应用所访问的 World Monitor 服务**：本地处理器缺失时提供响应的云端回退、授权与许可密钥校验、更新检查，以及该应用获取的任何托管数据。使用这些即是在使用服务，适用你的套餐范围。

由此可得：

- **完全使用你自己的 API 密钥与本地来源**运行桌面版本，且不调用 World Monitor 服务器的，仅受 AGPL 管辖。你无需从我们这里获得任何套餐。
- 一旦该应用获取 World Monitor 数据 —— 通过云端回退、授权校验或我们的 API —— 该次获取即受本协议管辖。
- 修改后的版本必须遵守[商标政策](/zh/trademark-policy)：使用不同的品牌标识，不得将修改版本呈现为官方 World Monitor 应用。
- 桌面端与网页端是**同一份许可，而非两份**。一个 Pro 席位对应一个人，无论此人使用浏览器还是桌面应用；同时使用两者不会占用两个席位。
