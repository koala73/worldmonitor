以下工具暂仅提供英文参考：[`get_gold_intelligence`](/mcp-tools/markets#get_gold_intelligence)、[`get_stock_research`](/mcp-tools/markets#get_stock_research)。

`curl` 示例假设已执行 `export WM_KEY="wm_…"`；使用 OAuth 时，请将 `-H "X-WorldMonitor-Key: $WM_KEY"` 替换为 `-H "Authorization: Bearer $TOKEN"`。

### `get_market_data`

来自 WorldMonitor 精选引导缓存的实时股票报价、大宗商品价格、SGE 实物金银相对 COMEX 的溢价与背离状态、加密货币价格、外汇汇率（USD/EUR、USD/JPY 等）、板块表现及估值覆盖、ETF 资金流和海湾市场报价。

`symbols` 仅筛选已发布的精选快照。未收录的代码不会触发任意代码查询。

**参数（工具特定）：**

| 名称 | 类型 | 描述 |
|------|------|-------------|
| `symbols` | `array<string>` | 要保留的代码，例如 ["AAPL","GC=F","BTC"]。不区分大小写；匹配股票/大宗商品/加密货币/海湾报价、实物溢价与背离别名、板块 ETF 和 ETF 资金流代码。省略则返回完整快照。 |
| `asset_class` | `array<string: equity / commodity / crypto / sectors / etf / gulf / sentiment>` | 将响应限制为一个或多个资产类别。省略则返回全部。 |
| `limit` | number | 将每个类别的报价列表（股票/大宗商品/加密货币/海湾/板块/ETF 资金流）限制为最多这么多项（默认 30，传 0 表示不限）。 |
| `refresh` | boolean | 默认为 false，复用付费市场面板。true 开始一次新的额度分配，必须提供 `request_id`。刷新时省略 `panel_request`。 |
| `request_id` | string (UUID) | 固定的刷新 ID。同一 UUID 的重试复用额度与原始到期时间。UUID 字母大小写不改变其身份。 |
| `panel_request` | string | 服务器签发的市场凭据，用于有界的精选数据读取。API 套餐不接受付费面板凭据。 |

- **API 端点：** `GET /api/market/v1/get-fear-greed-index`, `GET /api/market/v1/get-physical-divergence-index`, `GET /api/market/v1/get-physical-premiums`, `GET /api/market/v1/get-sector-summary`, `GET /api/market/v1/list-commodity-quotes`, `GET /api/market/v1/list-crypto-quotes`, `GET /api/market/v1/list-etf-flows`, `GET /api/market/v1/list-gulf-quotes`, `GET /api/market/v1/list-market-quotes`
- **类型：** 缓存读取 — 来自 Redis 引导缓存的亚秒级响应。
- **付费面板计量：** Pro 与 Pro Business 首次打开市场面板扣一次额度。五分钟复用窗口内的精选筛选和重复打开复用同一份分配。响应中的 `panelRequest.token` 可作为 `panel_request` 用于到期前的授权读取。新的刷新 UUID 扣一次新额度。API 套餐仍按工具权重计费，免费账户仍使用每日免费额度。
- **数据范围：** 筛选仅选择已有的种子报价。面板凭据和刷新均不会读取任意代码、账户自选列表或新提供方数据。有效凭据允许重试不可用或陈旧的结果。上游故障不会退还首次分配的额度。
- **新鲜度预算：** `stale` 仅追踪市场和板块快照（各 **30 分钟**）。每日 `physicalPremiums` 与 `physicalDivergence` 由 `/api/health` 监控。需要判断年龄时，请读取时间戳和背离状态。详见[实物贵金属背离指数方法](/zh/methodology/physical-divergence-index)。
- 板块 `valuationCoverage` 将写入年龄（`stale`）与完整度（`sourceStatus`：`ok`、`partial` 或 `degraded`）分开。`stale` 描述的是种子写入本身，而非单条记录——刚写入的负载中仍可能包含较旧的估值。提供 `symbols` 筛选时，`valuationCount` 与 `expectedValuationCount` 会按筛选结果计算。`valuationCount` 同时统计实时获取与回放的记录；`currentValuationCount` 给出本轮真正实时获取的子集，当所有记录均为最新时会省略该字段。`staleValuationSymbols` 列出来自旧快照的代码——这些代码在 `valuations` 中**确实**有数值，其年龄由 `lastGood.fetchedAt` 给出（上限为 7 天快照 TTL）。`unavailableSymbols` 列出完全没有发布估值的代码，与 `staleValuationSymbols` 互不相交。`lastGood` 同时涵盖整条记录与借用的收益指标，并包含该快照时间戳。当没有任何记录是最新时 `sourceStatus` 为 `degraded`，当部分记录陈旧或缺失时为 `partial`。`valuationDiagnostics` 是按代码限制的路由元数据，覆盖 `v7Quote`、`v7QuoteBatch` 与 `quoteSummary` 路由，展示独立的 direct/proxy 结果、响应类别和缺失字段，绝不包含凭据。

  -H 'Content-Type: application/json' \
  -d '{
    "jsonrpc":"2.0","id":1,

### `get_company_intelligence`

来自 SEC EDGAR 与市场数据的逐公司企业情报（#5695）。公司身份通过 SEC 股票代码/名称注册表解析到 CIK：优先精确股票代码，或使用仅映射到单一 CIK 的 SEC 法定名称精确匹配。无法解析时，`enrichment` 返回 `sources: []` 且 `company.cik` 为空，`signals` 返回 `signals: []` 且 `cik` 为空。两种视图中，`unavailable: false` 表示未找到，`unavailable: true` 表示注册表或必需数据源未能响应。四种视图复用四条规范 REST 路由。

**参数（工具特定）：**

| 名称 | 类型 | 描述 |
|------|------|------|
| `view` | `string: enrichment / signals / filings-search / material-events` | 默认 `enrichment`。 |
| `ticker` | string | 交易所股票代码，例如 `AAPL`；是 `enrichment` 与 `signals` 的首选公司键。 |
| `name` | string | 无股票代码时的公司名称；仅接受映射到单一 CIK 的 SEC 法定名称精确匹配。 |
| `query` | string | 仅 `filings-search`：必填全文查询。 |
| `forms` | string | 仅 `filings-search`：逗号分隔的表单筛选，例如 `8-K` 或 `10-K,10-Q`。 |
| `start_date` / `end_date` | string | 仅 `filings-search`：申报日期范围（YYYY-MM-DD）。 |
| `item_code` | string | 仅 `material-events`：筛选一个 8-K 条目代码，例如 `5.02`。 |
| `limit` | integer | `filings-search` 最多 25，`material-events` 最多 100；超出视图上限会被拒绝。 |

- **API 端点：** `GET /api/intelligence/v1/get-company-enrichment`、`GET /api/intelligence/v1/list-company-signals`、`GET /api/intelligence/v1/search-sec-filings`、`GET /api/intelligence/v1/list-material-events`
- **类型：** 规范路由代理 — `enrichment` 汇总 SEC、Finnhub 盈利事实与新闻；`signals` 仅使用具备权威时间戳的 SEC 申报与新闻，不把财政期末当作事件时间。
- **新鲜度：** 每个视图都携带自己的真实来源时间戳（`enrichedAtMs`、`discoveredAtMs` 或 `fetchedAtMs`）。

<CodeGroup>

```bash curl
curl -s https://worldmonitor.app/mcp \
  -H "X-WorldMonitor-Key: $WM_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "jsonrpc":"2.0","id":1,
    "method":"tools/call",
    "params":{"name":"get_company_intelligence","arguments":{"ticker":"AAPL","view":"signals"}}
  }'
```

</CodeGroup>

### `get_prediction_markets`

预测市场：`geopolitical`（地缘政治/选举）、`tech`（有标签的科技，包括人工智能、加密货币和科学）、`finance`（金融/经济或未分类回退）。合约包含当前概率。Kalshi 目前不提供分类器标签，因此 `source=kalshi` 与 `category=tech` 组合不会返回记录；其他非地缘政治 Kalshi 记录会回退到 `finance`。专属付费连接的打开和筛选共用一次面板分配。附带 `request_id` 的显式刷新开始一次新分配，同一 ID 的重试复用该分配。API 套餐仍按工具权重计费。

**参数（工具特定）：**

| 名称 | 类型 | 描述 |
|------|------|-------------|
| `category` | string: geopolitical / tech / finance | 限制为一个市场类别桶。省略则返回全部三类。`finance` 也接收未分类的非地缘政治记录。 |
| `query` | string | 仅保留标题包含此文本的市场（不区分大小写）。 |
| `source` | string: kalshi / polymarket | 筛选为一个预测市场来源。Kalshi 目前不提供分类器标签，因此与 `category=tech` 组合不会返回记录。 |
| `sort` | string: rank / move_24h / move_7d | 默认 `rank` 保留种子排序。`move_24h` 和 `move_7d` 在每个类别内按变化绝对值降序排列，然后应用 limit；缺失值排在最后。 |
| `min_liquidity` | number | 仅保留流动性（以美元计的挂单深度）不低于此值的市场，在 limit 之前应用。大于 0 时，没有流动性数据的市场（例如订单簿获取失败的 Kalshi 市场）会被排除。 |
| `limit` | number | 限制每个类别的记录数，默认 30。零或负数表示不限。正小数使用整数部分。 |
| `refresh` | boolean | 仅限付费面板。默认 false 复用预测分配。true 必须附带 UUID request_id，并开始一次新分配。刷新时省略 panel_request。 |
| `request_id` | string | 付费刷新 UUID。同一 UUID 的重试复用分配及原始到期时间，字母大小写不改变身份。 |
| `panel_request` | string | 服务器签发的预测凭据，用于到期前的授权精选读取。API 和免费账户调用不接受该凭据。 |

- **概率变化：** 可选 `change24h` 和 `change7d` 为 `yesPrice` 0–100 标度的百分点变化。上游缺失时不返回该字段，零表示没有变化。Kalshi 仅提供 24 小时变化。REST 的 `yesPriceChange24h` 和 `yesPriceChange7d` 使用 0–1 概率标度。
- **流动性：** 可选 `liquidity` 为按交易场所计算的美元挂单深度。Polymarket 记录使用 Gamma 的 CLOB 流动性（`liquidity`，等于 `liquidityClob`）：类别桶记录为事件级，国家记录为合约级。Kalshi 记录对合约订单簿中全部 yes 与 no 买单的价格乘以数量求和。两个场所的计算方式不同，阈值宜在同一来源内比较。场所未报告或订单簿获取失败时不返回该字段。REST 以 `min_liquidity` 接受同一筛选。
- **API 端点：** `GET /api/prediction/v1/list-prediction-markets`
- **访问：** `free-account`，任意已登录账户均可调用。免费账户消耗每日免费额度，API 套餐仍按工具权重计费。接受通用 `summary` 参数。
- **付费面板计量：** Pro 与 Pro Business 打开面板扣一次额度。规范化筛选与重复打开在五分钟内复用预测分配。返回的 `panelRequest.token` 在到期前授权精选预测读取。本地类别展开只读取已加载数据，不发起新的工具调用。每份分配最多允许 64 次未缓存工具执行，未缓存执行与已确认缓存回放分别限制为每分钟 64 次。工具执行次数不等于单条 Redis 命令数。
- **付费参数校验：** 类别和来源去除两端空白并忽略大小写。标题查询忽略大小写和两端空白。付费调用在预留额度前拒绝未知参数、无效类别或来源，以及非有限数值或非数字的 limit。普通 API 和免费账户调用保留既有筛选转换行为，不接受刷新控制或付费凭据。
- **复用与恢复：** 相同规范化筛选在 summary 或 JMESPath 投影前复用成功的原始结果。新的未缓存筛选读取既有引导数据与新鲜度元数据。新鲜且有效的筛选空结果可以复用。陈旧、不可用、格式错误或未知观察仍可在同一凭据下重试。上游故障不退还已分配额度。
- **用量通知：** 显式授权凭据读取同时查询当前每日额度，不再预留单位。计数器不可用或未确认时，保留合约数据而不显示数值通知。旧的打开通知不能证明后续计数。
- **类型：** Redis 引导缓存读取。
- **新鲜度预算：** 标记 `stale: true` 前最多 **1.5 小时**（由 seeder cron 的预期间隔设定）。
