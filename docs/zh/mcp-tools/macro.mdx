### `get_economic_data`

宏观经济指标：联邦基金利率（FRED）、经济日历事件、燃料价格、ECB 外汇汇率、俄罗斯央行官方卢布汇率与关键政策利率、EU 收益率曲线、财报日历、COT 持仓、能源存储数据、BIS 家庭偿债比率（DSR，季度，约 40 个发达经济体家庭财务压力的领先指标），以及 BIS 住宅 + 商业地产价格指数（实际值，季度）。

**参数（工具特定）：**

| 名称 | 类型 | 描述 |
|------|------|-------------|
| `dataset` | `array<string: fedfunds / econ-calendar / china-macro / china-release-calendar / fuel-prices / ecb-fx-rates / cbr-rates / yield-curve-eu / spending / earnings-calendar / cot / dsr / property-residential / property-commercial>` | 将响应限制为一个或多个子数据集。省略则返回完整经济捆绑包。 |
| `country` | string | 将按国家键控的数据集（燃料价格、BIS DSR/地产、经济日历）筛选为一个 ISO 3166-1 alpha-2 代码。 |
| `limit` | number | 将每个列表数据集（日历、支出、财报）限制为最多这么多项（默认 30，传 0 表示不限）。 |

- **API 端点：** `GET /api/economic/v1/get-ecb-fx-rates`, `GET /api/economic/v1/get-economic-calendar`, `GET /api/economic/v1/get-eu-yield-curve`, `GET /api/economic/v1/list-fuel-prices`, `GET /api/market/v1/get-cot-positioning`, `GET /api/market/v1/list-earnings-calendar`
- **类型：** 缓存读取 — 来自 Redis 引导缓存的亚秒级响应。
- **新鲜度预算：** 标记 `stale: true` 前最多 **1 天**（由 seeder cron 的预期间隔设定）。
- **分数据集提示：** 单一的 `stale` 标记仅由部分子数据集推导得出，并非逐数据集的保证。`cbr-rates` 不在其中——它每日发布，采用 3 天陈旧度预算与 14 天内容时效契约，二者均由 `/api/health` 监控，而非通过此标记。若特别关心该数据集的时效，请读取 `cbr-rates.effectiveDate`。

<CodeGroup>

```bash curl
curl -s https://worldmonitor.app/mcp \
  -H "X-WorldMonitor-Key: $WM_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "jsonrpc":"2.0","id":1,
    "method":"tools/call",
    "params":{"name":"get_economic_data","arguments":{}}
  }'
```

</CodeGroup>


### `get_fred_series`

**Access:** `subscription`.

通过规范的 `POST /api/economic/v1/get-fred-series-batch` RPC 查询仪表盘共用的预写入宏观序列缓存和允许列表，不会在请求时调用 FRED。`series_ids` 的实时说明列出所有支持的 ID，包括 `UNRATE`、`CPIAUCSL` 和 `FEDFUNDS`。

**Parameters (tool-specific):**

| Name | Type | Description |
| --- | --- | --- |
| `series_ids` | `array<string>` | 必填，FRED 序列 ID，统一为大写，最多转发 20 个；规范读取器忽略允许列表外的 ID。 |
| `limit` | integer | 每个序列的观测数，最新值在末尾。默认 24，有效范围 1–1000。 |

返回以序列 ID 为键的 `results`，含标题、单位、频率与观测值。`requested` 是实际查询的唯一允许 ID 数，`fetched` 是缓存中存在的序列数；缓存缺失时不会触发刷新。大响应可能受 MCP 输出预算压缩。

示例：`get_fred_series({"series_ids":["UNRATE","CPIAUCSL"],"limit":24})`。

### `get_country_macro`

按 `dataset` 选择的逐国宏观经济指标。IMF WEO 覆盖约 210 个国家，每个序列取最新可用年份：

- `macro`：通胀、CPI、经常账户、政府收入、支出与初级余额。
- `growth`：实际 GDP 增长、人均 GDP（美元与 PPP）、储蓄与投资率、储蓄-投资缺口。
- `labor`：失业率与人口。
- `external`：经常账户（美元）与进口/出口量百分比变化。以美元计的出口/进口水平（`exportsUsd`、`importsUsd`、`tradeBalanceUsd`）返回 null，因为 WEO 在 2026-04 收回了 BX/BM 指标的广泛覆盖；请改用 `currentAccountUsd` 或量变化。

Eurostat 覆盖 27 个欧盟成员国以及 EA20 与 EU27_2020 汇总：

- `house-prices`：年度房价指数（prc_hpi_a，2015=100），附 10 年序列。
- `gov-debt-q`：季度一般政府总债务（gov_10q_ggdebt，占 GDP 百分比），附 8 个季度序列。
- `industrial-production`：月度工业生产指数（sts_inpr_m，NACE B-D 不含建筑业，经季节与日历调整，2021=100），附 12 个月序列。

每个 Eurostat 国家条目包含 `value`、`priorValue`、`hasPrior`、`date`、`unit` 与 `series`。

**参数（工具特定）：**

| 名称 | 类型 | 描述 |
|------|------|-------------|
| `dataset` | `array<string: macro / growth / labor / external / house-prices / gov-debt-q / industrial-production>` | 将响应限制为一个或多个数据集。省略则返回全部七个。 |
| `countries` | `array<string>` | 在每个数据集中要保留的 ISO 3166-1 alpha-2 国家代码（例如 ["US","DE","GR"]）；希腊在 Eurostat 数据集中以 EL 为键。EA20 与 EU27_2020 选择 Eurostat 汇总。省略则返回全部。接受国家名称与 alpha-3 代码；无法解析的输入返回 Invalid params。 |
| `limit` | integer | 在未提供 countries 筛选时，将每个数据集国家映射限制为最多这么多条目（默认 30，传 0 表示不限）。 |

IMF 映射以 ISO-2 为键，Eurostat 映射以 Eurostat 地理代码为键，因此一次 `countries: ["Greece"]` 调用会在 IMF 数据集中返回 `GR`，在 Eurostat 数据集中返回 `EL`。

- **API 端点：** 无直接端点 — 从引导聚合缓存键读取（无 1:1 REST 端点）。
- **类型：** 缓存读取 — 来自 Redis 引导缓存的亚秒级响应。
- **新鲜度预算：** 按数据集 — IMF **70 天**，`house-prices` **50 天**，`gov-debt-q` **14 天**，`industrial-production` **5 天**。一次调用只读取所选数据集，并只据此判断 `stale`；省略 `dataset` 时按全部七个判断。

旧名称 `get_eu_housing_cycle`、`get_eu_quarterly_gov_debt` 与 `get_eu_industrial_production` 已退役，但仍可调用：它们以各自的数据集调用 `get_country_macro`，并返回指明替代工具的 `deprecation` 通知。

<CodeGroup>

```bash curl
curl -s https://worldmonitor.app/mcp \
  -H "X-WorldMonitor-Key: $WM_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "jsonrpc":"2.0","id":1,
    "method":"tools/call",
    "params":{"name":"get_country_macro","arguments":{"dataset":["gov-debt-q"],"countries":["DE","EL","EA20"]}}
  }'
```

</CodeGroup>

### `get_price_and_debt_indicators`

价格和债务指标：巨无霸指数、FAO 食品价格指数和各国国家债务水平。

原名 `get_tariff_trends`。旧名上仅含 tariffs 的调用会运行 `get_tariff_averages` 并返回美国 MFN 序列。旧名上的其他数据集仍返回本捆绑包。自 #9301 起本捆绑包不含关税序列。美国 MFN 序列属于 Pro 数据。请调用 `get_tariff_averages`，报告国设为 `840`，不传伙伴和产品组。在本工具上使用 `dataset: ["tariffs"]` 会返回 Invalid params。

**参数（工具特定）：**

| 名称 | 类型 | 描述 |
|------|------|-------------|
| `dataset` | `array<string: bigmac / fao-ffpi / national-debt>` | 将响应限制为一个或多个子数据集。省略则返回完整捆绑包。 |
| `country` | string | 将按国家数据集筛选为一个 ISO 3166-1 alpha-2 国家代码（例如 "US"）。内部会为 national-debt 数据集转换为 alpha-3；直接传 alpha-3 代码也可。 |
| `limit` | number | 将每个列表数据集（BigMac 国家、债务条目）限制为最多这么多项（默认 30，传 0 表示不限）。 |

- **API 端点：** `GET /api/economic/v1/get-fao-food-price-index`, `GET /api/economic/v1/get-national-debt`, `GET /api/economic/v1/list-bigmac-prices`
- **类型：** 缓存读取 — 来自 Redis 引导缓存的亚秒级响应。
- **新鲜度预算：** 按子数据集计算 — BigMac **7 天**，FAO FFPI 和国家债务各 **60 天**。任一子数据集超出自身预算时，`stale` 即为 true。

### `get_capital_flows`

返回约 230 个经济体资金的流入与流出,以及任意两个经济体之间的资金往来,数据来自官方统计。IMF 国际收支:总流入与总流出,按 FDI、证券投资和其他投资拆分,按国家为季度或年度数据,并附推导的 Forbes-Warnock 状态(流入为 surge 或 stop,流出为 flight 或 retrenchment)及 z 分数。按国家和按国家对:BIS 跨境银行存款与贷款、IMF 证券投资持有和 IMF 直接投资头寸。居民身份变更不是国际收支流量。来源滞后 1–3 个季度(FDI 约 2 年);10 天未更新或最新国际收支季度超过一年时标记为过期。缓存读取:API 套餐权重 1,计入已登录账户的免费额度。country(最多 10 个)返回完整视图;counterpart 增加每个国家对的双向数据,每个分项标注 reported、not_itemized 或 not_published。不指定 country 时,对具备排序指标的国家排名(默认 outflow_z;仅有年度数据的序列没有该指标),按 limit 截断(默认 30,传 0 不限)。

适用于任意经济体和任意国家对:传入多个 `country` 进行比较,加上 `counterpart` 获取双边明细,或省略 `country`,对具备所选 `sort` 指标的经济体排名(默认 `outflow_z` 不含仅有年度数据、没有 z 分数的序列)。阶段标签按 Forbes 与 Warnock(2012)方法由已报告的流量推导。各视图、分项和状态的说明见[资本流动方法论](/zh/methodology/capital-flows)。

**参数(工具专用):**

| 名称 | 类型 | 说明 |
|------|------|-------------|
| `country` | `array<string>` | 返回完整视图的国家:ISO 3166-1 alpha-2、alpha-3 或英文名称。省略则返回跨国排名。 |
| `include_series` | boolean | 与 country 一起使用时,同时返回逐期国际收支流量(12 个季度或 6 年)。默认 false。 |
| `counterpart` | string | 与 country 一起使用的对手国(alpha-2、alpha-3 或名称)。返回 pairs[]:双方非银行在对方银行的存款和双向银行贷款(存量、四季度流量、八个季度历史),双方对彼此证券的持有,以及带双方数字的双向直接投资,另加对手国自身的视图。 |
| `sort` | `string: outflow_z / inflow_z / outflows_pct_gdp / inflows_pct_gdp / net_usd_bn / bank_deposits_abroad_flow_4q / foreign_portfolio_change_pct` | 省略 country 时的排名字段。默认 outflow_z。 |
| `ascending` | boolean | 升序排列。默认 false。 |
| `limit` | number | 排名最多返回的国家数(默认 30,传 0 表示不限)。传入 country 时忽略。 |

- **API 端点:** `GET /api/economic/v1/get-capital-flows`
- **访问:** `free-account` — 任何已登录账户均可调用;免费账户消耗每日免费额度,Pro 调用消耗每日配额。支持通用 `summary` 参数。
- **类型:** 缓存读取 — 从 Redis 亚秒级响应。
- **新鲜度预算:** 距上次每周种子 **10 天**,另有内容时效检查:最新 IMF 国际收支季度超过 12 个月时 `stale` 变为 true。

<CodeGroup>

```bash curl
curl -s https://worldmonitor.app/mcp \
  -H "X-WorldMonitor-Key: $WM_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "jsonrpc":"2.0","id":1,
    "method":"tools/call",
    "params":{"name":"get_capital_flows","arguments":{"country":["DE"],"counterpart":"JP"}}
  }'
```

</CodeGroup>
