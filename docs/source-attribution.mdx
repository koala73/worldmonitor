This page is the compliance companion to [Data Sources](/data-sources). Where that page explains **what** World Monitor covers and **which** providers power each domain, this one is the raw, machine-audited ledger: every upstream host observed in the source tree, what kind of surface it is (structured API, feed, or operational-status endpoint), the license posture we track for it, and the attribution it requires.

The inventory is **generated, not hand-written**: `scripts/source-attribution.mjs` scans URL literals in `scripts/`, `server/`, `api/`, and `src/`, and joins them against the committed manifest (`shared/source-attribution-manifest.json`). A host that appears in code but not in the manifest fails CI, so this disclosure cannot silently drift from what the code actually fetches. Status meanings:

| Status | Meaning |
|--------|---------|
| `reviewed` | License and attribution terms were reviewed; the stated credit is authoritative. |
| `terms-review` | The host is active, but its terms have not been individually reviewed — confirm before any redistribution or commercial-use claim. |
| `excluded` | Observed in code but not an ingested dataset (first-party transport, presentation-only stream, control plane) — excluded from provider counts. |
