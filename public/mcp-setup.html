World Monitor

Connect your AI assistant to World Monitor.

Bring global intelligence on countries, markets, conflicts, and supply chains into your conversations using the Model Context Protocol (MCP).

Server URL

https://worldmonitor.app/mcp
  1. Add the server. Open your assistant’s MCP or custom connector settings and paste the URL above. Choose OAuth if asked.
  2. Sign in. Use your World Monitor account and authorize the connection. A free account works; access and daily allowances depend on your plan.
  3. Ask a question. Try “What are the biggest global risks today?”

Setup guide for Claude, ChatGPT, Codex, and Cursor →

Terminal setup

Codex

codex mcp add worldmonitor --url https://worldmonitor.app/mcp
codex mcp login worldmonitor

Claude Code

claude mcp add --transport http worldmonitor https://worldmonitor.app/mcp

Then run /mcp, select worldmonitor, and choose Authenticate.

This address is also the live MCP endpoint using Streamable HTTP. MCP clients connect to the same URL. See the MCP overview or Markdown server guide for more details.
