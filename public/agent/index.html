World Monitor

World Monitor for AI agents

World Monitor: real-time geopolitical intelligence dashboard. A free live map of conflicts, shipping, flights, markets and cyber, with an API and MCP server.

Give Claude, ChatGPT, Cursor, Gemini, Grok Bot or any MCP client the same live data the dashboard shows: one remote MCP server with 90+ MCP tools, a REST API, and ready-made skills.

What agents get

MCP server
https://worldmonitor.app/mcp
90+ MCP tools over Streamable HTTP: conflict events, chokepoints and vessel traffic, military flights, markets, cyber threats, country risk, forecasts and news digests. MCP reference
REST API
The same data as JSON over HTTPS with an X-WorldMonitor-Key header, described by an OpenAPI spec. API reference
Skills
Task recipes your agent can load on demand, installed with one command. Install skills

Signing in needs only a free World Monitor account, and get_sources works without one. Most data tools need a Pro or API plan; see plans.

Connect your agent

Every client uses the same server URL. When it connects, a browser window asks you to sign in to World Monitor and approve access (OAuth). No key to copy.

Claude

Claude and Claude Desktop: open Customize > Connectors, click + Add and choose Add custom connector (some accounts show Custom > Web instead). Name it World Monitor, paste the URL below, click Continue, keep the detected sign-in settings, click Add, then connect and sign in. On Team and Enterprise plans an owner adds it first under Organization settings > Connectors, and members then click Connect. The Free plan allows one custom connector.

https://worldmonitor.app/mcp

Claude Code: add the server, then run /mcp in a session to sign in.

claude mcp add --transport http worldmonitor https://worldmonitor.app/mcp

ChatGPT

Full MCP support is available on ChatGPT web for Business, Enterprise and Edu plans. On Business, only workspace admins and owners can create custom MCP connections. On Enterprise and Edu, admins can also give selected members permission to create connections. Only admins and owners can publish connections for the workspace. Pro supports custom MCP connections with read/fetch permissions. Check OpenAI’s current requirements before setup.

With permission to create a connection, open Plugins, click the plus button and choose Add custom MCP server. Enter World Monitor as the name and the URL below as the server URL. Choose OAuth, confirm the warning, then create and install the plugin. Start a chat and pick World Monitor with @.

https://worldmonitor.app/mcp

Cursor

Add this to ~/.cursor/mcp.json for every project, or .cursor/mcp.json for one. Cursor opens the sign-in window the first time the server starts.

{
  "mcpServers": {
    "worldmonitor": {
      "url": "https://worldmonitor.app/mcp"
    }
  }
}

Gemini CLI

Add the server (use -s user to make it available in every project), then run /mcp auth worldmonitor inside Gemini CLI to sign in.

gemini mcp add --transport http worldmonitor https://worldmonitor.app/mcp

Or add it to ~/.gemini/settings.json by hand:

{
  "mcpServers": {
    "worldmonitor": {
      "httpUrl": "https://worldmonitor.app/mcp"
    }
  }
}

Grok Bot

In a Grok Bot chat, ask it to add the server, confirm, and sign in when the approval window opens. Then mention World Monitor with @ in any chat.

Add this MCP server: https://worldmonitor.app/mcp

On grok.com, open Connectors, choose New Connector, then Custom, and paste the same URL.

Any other MCP client

Point it at the Streamable HTTP endpoint below. Clients that support OAuth register themselves and open the sign-in window. Clients that send headers can use an API key instead: X-WorldMonitor-Key: wm_.... Stdio-only clients can connect through mcp-remote.

https://worldmonitor.app/mcp

Check the connection and browse the tools with the MCP Inspector:

npx @modelcontextprotocol/inspector --server-url https://worldmonitor.app/mcp --transport http

Install the skills

Skills are folders with a SKILL.md recipe that tells an agent which World Monitor endpoint answers which question. The skills CLI installs them into Claude Code, Cursor, Codex, Gemini CLI and other agents. Pick skills and agents interactively:

npx skills add koala73/worldmonitor

Install one skill for one agent, or every skill for every supported agent in your user profile:

npx skills add koala73/worldmonitor --skill check-chokepoint-status --agent claude-code
npx skills add koala73/worldmonitor --all --global

Skills call the REST API, so set an API key from your account in X-WorldMonitor-Key. Available skills:

  • assess-energy-shock Model oil or gas supply shock exposure for a country and chokepoint.
  • check-airport-delays Retrieve current airport delay and cancellation alerts worldwide — delay type, severity, average delay minutes, and affected-flight percentages per airport.
  • check-chokepoint-status Retrieve live disruption status for the 13 monitored maritime chokepoints (Suez, Hormuz, Malacca, Bab el-Mandeb, Panama, and more).
  • check-country-risk Retrieve composite country risk intelligence — Country Instability Index (CII), travel advisory level, and active sanctions exposure — for one country by ISO code.
  • check-forecast-signals Retrieve probabilistic forecasts and their scorecard context.
  • check-sanctions-pressure Retrieve normalized OFAC sanctions pressure — designation summaries, recent additions, and per-country/per-program aggregates including sanctioned vessels and aircraft.
  • compare-macro-history Compare CPI, interest rates and sovereign yield histories from seeded official reports.
  • fetch-country-brief Open the WorldMonitor country interface in a UI-capable MCP host.
  • fetch-news-digest Retrieve the pre-aggregated digest of World Monitor's curated news feeds, bucketed by category, with per-article threat classification and alert flags.
  • fetch-resilience-score Retrieve the composite country resilience score (0-100) and its domain/pillar breakdown for a single country.
  • get-market-quotes Retrieve real-time equity, index, and ETF quotes with price, change, and sparkline history.
  • get-prediction-markets Retrieve active prediction-market contracts (Polymarket) with live yes-price probabilities, volume, and close dates, filterable by category or keyword.
  • lookup-bilateral-tariff Look up the applied tariff on one HS6 product imported by one country from another (MFN, partner-specific preferential, and the best available applied rate), from UNCTAD TRAINS via World Bank WITS.
  • lookup-us-import-duty Look up the current US import duty on one HTS product from one country — the HTS column rate (MFN, trade-agreement or column 2) plus the Section 301 and 232 duties in chapter 99 — from the live USITC Harmonized Tariff Schedule.
  • monitor-energy-disruptions Retrieve the curated energy disruption event log for pipelines and storage facilities.
  • monitor-health-alerts Retrieve disease outbreak alerts and PM2.5 air-quality health warnings.
  • monitor-internet-outages Retrieve detected internet outages (Cloudflare Radar) with country, cause, severity, and time bounds.
  • monitor-supply-chain-stress Retrieve current shipping market stress from carrier and freight indicators.
  • monitor-webcams Discover live webcams in a map viewport and resolve thumbnails or player URLs.
  • research-stocks Read current stock research, technical backtests, saved analyses or saved backtests.
  • scan-cyber-threats Retrieve active cyber-threat intelligence — malware IOCs, C2 infrastructure, and CISA known-exploited vulnerabilities — filterable by type, source, and severity.
  • trace-trade-flows Retrieve strategic UN Comtrade commodity flows with anomaly flags.
  • track-climate-hazards Retrieve climate-relevant disaster events, anomalies, and climate news.
  • track-conflict-events Retrieve geolocated armed-conflict events (UCDP) with parties, fatality estimates, and violence type, filterable by country and date range.
  • track-earthquakes Retrieve recent earthquakes (USGS) with magnitude, depth, location, and a concern score that flags proximity to nuclear test sites.
  • track-military-flights Retrieve tracked military aircraft positions (OpenSky + Wingbits) with callsign, type, operator, altitude, and activity clusters, filterable by bounding box, operator, and aircraft type.
  • track-tariff-trends Retrieve a country's average applied tariff over time — the MFN rate on all products, or the rate it applies on goods from one partner and/or in one product group — plus the optional US effective tariff rate.
  • track-unrest-events Retrieve seeded protest, riot, strike, and civil unrest events.
  • track-vessel-traffic Retrieve a point-in-time AIS vessel-traffic snapshot with disruption candidates and optional tanker overlay, filterable by bounding box.
