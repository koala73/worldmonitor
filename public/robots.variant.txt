# Variant-host robots (#6835). Shared corpus is canonical on www.
# Prefixes that 308 to www are NOT Disallowed — a crawler must fetch them to
# observe the redirect. /pro/welcome.html stays 200 here, so /pro is Disallowed.
# `Allow: /dashboard$` is end-anchored (#7660): the bare document stays
# explicitly crawlable, but unanchored `/dashboard` is 10 characters and so
# out-ranks the `/*?*lat=`, `/*?*lon=`, `/*?*zoom=`, `/*?*ref=` and `/*?*utm_`
# rules below (8-9). Any map URL that omits `layers` would slip straight
# through on exactly the path that generates the space.
# Named AI groups restate the * rules — robots.txt groups do not inherit.
#
# Crawl-budget disallows (#7660) mirror robots.www.txt: parameterised map-state
# and attribution URLs, already consolidated by rel=canonical. The variant hosts
# contributed 415 of the 1,000 exported redirect URLs. Rules are query-scoped
# (`/*?*`) so /dashboard and the 308 families stay crawlable, and the /embed
# carve-outs keep the documented iframe fetchable. /docs/_next/ is deliberately
# left crawlable for the reason recorded in robots.www.txt.
